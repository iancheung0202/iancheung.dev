Rules for Linear Dependence (LD)

A set of vectors is Linearly Dependent (LD) if one vector can be written as a linear combination of the others (equivalently, if \(c_1\mathbf{v}_1+\cdots+c_n\mathbf{v}_n=\mathbf{0}\) has a nontrivial solution).

Rule 1If 0 is in the collection → LD (the zero vector is always a linear combination of anything).
Rule 2If two vectors are scalar multiples of each other → LD.
Rule 3More columns than rows (more vectors than dimension) → LD.
Rule 4Repeated vectors in the collection → LD.
Rule 5Any vector is a multiple of another in the collection → LD.
Rule 6One vector is a linear combination of the others → LD.
Linear Independence & Spanning
Theorem — Linear Independence (LI) A set \(\{\mathbf{v}_1,\ldots,\mathbf{v}_n\}\) is Linearly Independent if and only if the only solution to \[c_1\mathbf{v}_1+c_2\mathbf{v}_2+\cdots+c_n\mathbf{v}_n=\mathbf{0}\quad\text{is}\quad c_1=c_2=\cdots=c_n=0.\] How to check: Form a matrix with the vectors as columns and row-reduce. The set is LI if and only if every column has a pivot (no free variables).
Theorem — Spanning \(\mathbb{R}^n\) A set of vectors spans \(\mathbb{R}^n\) if and only if every vector in \(\mathbb{R}^n\) can be written as a linear combination of them. Check: the matrix formed by the vectors has a pivot in every row.
Square Matrix Theorem (All or Nothing) For an \(n\times n\) square matrix: \[\text{LI} \iff \text{Spanning } \mathbb{R}^n \iff \text{Invertible} \iff \det(A)\neq 0.\] All four properties hold simultaneously or all fail.
Solutions to \(A\mathbf{x}=\mathbf{b}\)
Existence (Consistency) The system \(A\mathbf{x}=\mathbf{b}\) is consistent (has at least one solution) if and only if the rightmost column of the augmented matrix \([A|\mathbf{b}]\) is NOT a pivot column, i.e., no row of the form \([0\ 0\ \cdots\ 0\ |\ c]\) with \(c\neq 0\) appears.
Uniqueness If the system is consistent, the solution is unique if and only if there are no free variables (every variable corresponds to a pivot column). If there is at least one free variable (non-pivot column), there are infinitely many solutions.

Echelon Forms
Row Echelon Form (REF) Staircase pattern: each leading entry (pivot) is to the right of the pivot in the row above. All zeros below each pivot. Rows of all zeros at the bottom.
Reduced Row Echelon Form (RREF) REF plus: each pivot is 1, and all entries above and below each pivot are 0. RREF is unique.
Important Notes • \(A\mathbf{x}=\mathbf{b}\) has the same solution set as \(x_1\mathbf{a}_1+\cdots+x_n\mathbf{a}_n=\mathbf{b}\) where \(\mathbf{a}_i\) are columns of \(A\).
• \(A\mathbf{x}=\mathbf{b}\) has a solution iff \(\mathbf{b}\) is a linear combination of the columns of \(A\).
• \(A\mathbf{x}=\mathbf{0}\) always has the trivial solution \(\mathbf{x}=\mathbf{0}\); a nontrivial solution exists iff there is a free variable.
Linear Transformations
Definition A function \(T:V\to W\) is a linear transformation if and only if all three hold:
  1. \(T(\mathbf{u}+\mathbf{v})=T(\mathbf{u})+T(\mathbf{v})\) for all \(\mathbf{u},\mathbf{v}\in V\)
  2. \(T(c\mathbf{u})=cT(\mathbf{u})\) for all scalars \(c\) and \(\mathbf{u}\in V\)
  3. \(T(\mathbf{0})=\mathbf{0}\) (follows from 2 with \(c=0\), but good to verify)
Finding the Standard Matrix \([T]\) If \(T:\mathbb{R}^n\to\mathbb{R}^m\), the standard matrix has columns \(T(\mathbf{e}_1), T(\mathbf{e}_2),\ldots,T(\mathbf{e}_n)\) where \(\mathbf{e}_i\) are the standard basis vectors: \[[T]=\begin{bmatrix}|&|&&|\\ T(\mathbf{e}_1)&T(\mathbf{e}_2)&\cdots&T(\mathbf{e}_n)\\ |&|&&|\end{bmatrix}\] Then \(T(\mathbf{x})=[T]\mathbf{x}\) for all \(\mathbf{x}\).
Kernel and Image
Image / Column Space \[\text{Img}(T)=\{T(\mathbf{v})\mid \mathbf{v}\in V\}\] If \(T\) is represented by matrix \(A\): Img\((T)=\text{Col}(A)\) = span of columns of \(A\).
Kernel / Null Space \[\text{Ker}(T)=\{\mathbf{v}\in V\mid T(\mathbf{v})=\mathbf{0}\}\] If \(T\) is matrix \(A\): Ker\((T)=\text{Nul}(A)=\{\mathbf{x}\mid A\mathbf{x}=\mathbf{0}\}\).

Key Fact For square matrices: injective \(\Leftrightarrow\) surjective \(\Leftrightarrow\) invertible. If \(\det(A)=\pm1\) and \(A\) has integer entries, then \(A^{-1}\) also has integer entries (pure rotation/inversion).
Linear Subspaces
Definition A subset \(V_0\subseteq V_1\) is a linear subspace of \(V_1\) if and only if:
  1. \(V_0\) is non-empty (equivalently, \(\mathbf{0}\in V_0\))
  2. \(V_0\) is closed under scalar multiplication: if \(\mathbf{u}\in V_0\) then \(c\mathbf{u}\in V_0\)
  3. \(V_0\) is closed under addition: if \(\mathbf{u},\mathbf{v}\in V_0\) then \(\mathbf{u}+\mathbf{v}\in V_0\)
Both Ker\((T)\) and Img\((T)\) are always subspaces.
Basis and Dimension
Definition A basis of a vector space \(V\) is a collection of vectors that is simultaneously:
  • Linearly Independent, and
  • Spanning (every vector in \(V\) is a unique linear combination of basis vectors).
The dimension of \(V\) = number of vectors in any basis. Every basis has the same size.
Key Facts • If \(V\) has a basis of \(n\) vectors, any set of >\(n\) vectors in \(V\) must be LD.
• Every basis of \(V\) has exactly \(n\) vectors.
• Polynomial space \(\mathcal{P}_n\) (degree \(\leq n\)): dimension \(= n+1\), basis \(= \{1, x, x^2, \ldots, x^n\}\).
Change of Basis
Four Key Formulas
1
To find coordinates of \(\mathbf{v}=[a,b]^T\) (in old basis \(\{\mathbf{e}_1,\mathbf{e}_2\}\)) in new basis \(\mathcal{B}'=\{\mathbf{e}_1',\mathbf{e}_2'\}\): solve \([\mathbf{e}_1'\ \mathbf{e}_2'][x,y]^T=[a,b]^T\), i.e., multiply both sides by the inverse of the change-of-basis matrix.
2
To compute \(P_{\mathcal{B}\to\mathcal{C}}\) (change-of-basis from \(\mathcal{B}\) to \(\mathcal{C}\)): row-reduce \([\mathbf{c}_1\ \mathbf{c}_2\ |\ \mathbf{b}_1\ \mathbf{b}_2]\sim[I\ |\ P]\). Then \(P=P_{\mathcal{B}\to\mathcal{C}}\).
3
\(P_{\mathcal{B}\to\mathcal{C}}^{-1}=P_{\mathcal{C}\to\mathcal{B}}\).
4
If you know the relationship directly, e.g., \(\mathbf{b}_1=4\mathbf{c}_1+\mathbf{c}_2\) and \(\mathbf{b}_2=-6\mathbf{c}_1+\mathbf{c}_2\), just read off columns: \(P_{\mathcal{B}\to\mathcal{C}}=\begin{bmatrix}4&-6\\1&1\end{bmatrix}\).
Past Exam Example — \(T:\mathcal{P}_2\to\mathcal{P}_2\) Let \(T(f)=t^2f''+f'+f\). Find the matrix of \(T\) relative to basis \(\mathcal{B}=\{1,t,t^2\}\).
Apply \(T\) to each basis vector:

\(T(1):\; f=1,\; f'=0,\; f''=0 \;\Rightarrow\; T(1)=t^2(0)+0+1=1=1\cdot1+0\cdot t+0\cdot t^2\) → column \([1,0,0]^T\)

\(T(t):\; f=t,\; f'=1,\; f''=0 \;\Rightarrow\; T(t)=0+1+t=1+t=1\cdot1+1\cdot t+0\cdot t^2\) → column \([1,1,0]^T\)

\(T(t^2):\; f=t^2,\; f'=2t,\; f''=2 \;\Rightarrow\; T(t^2)=t^2(2)+2t+t^2=2t^2+2t+t^2=2t+3t^2\) → column \([0,2,3]^T\)

\[[T]_{\mathcal{B}}=\begin{bmatrix}1&1&0\\0&1&2\\0&0&3\end{bmatrix}\] Eigenvalues: since \([T]_\mathcal{B}\) is upper triangular, eigenvalues are the diagonal entries: \(\lambda=1,1,3\).

Key Determinant Properties
Essential Properties
  • Triangular matrix: \(\det(A)=\) product of diagonal entries.
  • Scaling whole matrix: \(\det(kA)=k^n\det(A)\) for an \(n\times n\) matrix.
  • Product rule: \(\det(AB)=\det(A)\det(B)\).
  • Transpose: \(\det(A^T)=\det(A)\).
  • Inverse: \(\det(A^{-1})=1/\det(A)\).
  • Area/Volume: \(|\det(A)|\) = area of parallelogram (in \(\mathbb{R}^2\)) or volume of parallelepiped (in \(\mathbb{R}^3\)) formed by the columns of \(A\).
  • Singular: \(\det(A)=0 \Leftrightarrow A\) is not invertible.
  • Integer matrix: If \(A\) has integer entries and \(\det(A)=\pm1\), then \(A^{-1}\) also has integer entries (\(\pm1\) det means pure rotation/inversion).
2×2 Inverse Formula \[\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}\qquad(\text{swap diagonal, negate off-diagonal, divide by det})\]
Orthogonal Matrix If \(A\) is orthogonal (\(A^{-1}=A^T\)): \(\det(A)=\pm1\).
Past Exam — Integer Matrix Proof Claim: If all entries of \(A\) and \(A^{-1}\) are integers, then \(\det A=\pm1\).

Proof: Since all entries of \(A\) are integers, \(\det A\in\mathbb{Z}\). Since all entries of \(A^{-1}\) are integers, \(\det(A^{-1})\in\mathbb{Z}\). But \(\det(A)\cdot\det(A^{-1})=\det(AA^{-1})=\det(I)=1\). So two integers multiply to 1, which forces both to be \(\pm1\).

Converse: If entries of \(A\) are integers and \(\det A=\pm1\), use the adjugate formula: \(A^{-1}=\frac{1}{\det A}\text{adj}(A)\). Since \(\text{adj}(A)\) has integer entries (it's made of \((n-1)\times(n-1)\) minors of \(A\)) and \(\det A=\pm1\), all entries of \(A^{-1}\) are integers.
Column Space, Null Space, Rank, Nullity
Column Space / Col(A) Also called Range, Img\((A)\). The set of all possible outputs: \(\text{Col}(A)=\{A\mathbf{x}\mid\mathbf{x}\in\mathbb{R}^n\}\). It is the span of the columns of \(A\). Lives in the output space \(\mathbb{R}^m\).
Null Space / Nul(A) Also called Kernel. All inputs mapped to zero: \(\text{Nul}(A)=\{\mathbf{x}\mid A\mathbf{x}=\mathbf{0}\}\). Lives in the input space \(\mathbb{R}^n\).
Rank \(\text{rank}(A)=\dim(\text{Col}(A))=\) number of pivot columns in row echelon form.
Nullity \(\text{nullity}(A)=\dim(\text{Nul}(A))=\) number of free variables = number of non-pivot columns.
Rank-Nullity Theorem For any linear map \(T:V\to W\) (or \(m\times n\) matrix \(A\)): \[\text{rank}(T)+\text{nullity}(T)=\dim(V)=\text{number of columns of } A.\]
Finding Bases
Basis for Col(A) Row-reduce \(A\) to echelon form. Identify the pivot columns. Take the corresponding columns from the original matrix \(A\) (not from the reduced form) as the basis.
Basis for Nul(A) Solve \(A\mathbf{x}=\mathbf{0}\) (row-reduce \([A|0]\)). Express each free variable parametrically. Each free variable contributes one basis vector.
Example — Finding Nul Basis If row reduction gives \([\tilde{A}|\mathbf{0}]\sim\begin{bmatrix}1&0&-\frac{1}{2}&0\\0&0&1&0\end{bmatrix}\), then \(x_2\) is free (call it \(s\)), \(x_4\) is free (call it \(t\)): From row 2: \(x_3=0\). From row 1: \(x_1=\frac{1}{2}x_2=\frac{s}{2}\). So: \[\mathbf{x}=s\begin{bmatrix}\frac{1}{2}\\1\\0\\0\end{bmatrix}+t\begin{bmatrix}0\\0\\0\\1\end{bmatrix}\] Basis for Nul\((A)\): \(\left\{\begin{bmatrix}1/2\\1\\0\\0\end{bmatrix},\begin{bmatrix}0\\0\\0\\1\end{bmatrix}\right\}\).
Change of Basis — Detailed Procedure
Change-of-Basis Matrix \(P_{\mathcal{B}\to\mathcal{C}}\) To express vectors in basis \(\mathcal{B}\) using basis \(\mathcal{C}\): \[\text{Row-reduce}\quad[\mathbf{c}_1\ \mathbf{c}_2\ \cdots\ |\ \mathbf{b}_1\ \mathbf{b}_2\ \cdots]\sim[I\ |\ P_{\mathcal{B}\to\mathcal{C}}]\] Then: \([\mathbf{v}]_\mathcal{C}=P_{\mathcal{B}\to\mathcal{C}}[\mathbf{v}]_\mathcal{B}\).
Example — Direct Reading If \(\mathbf{b}_1=4\mathbf{c}_1+\mathbf{c}_2\) and \(\mathbf{b}_2=-6\mathbf{c}_1+\mathbf{c}_2\): \[P_{\mathcal{B}\to\mathcal{C}}=\begin{bmatrix}4&-6\\1&1\end{bmatrix}\] The columns record the \(\mathcal{C}\)-coordinates of each \(\mathcal{B}\)-vector. Note: \(P_{\mathcal{C}\to\mathcal{B}}=P_{\mathcal{B}\to\mathcal{C}}^{-1}\).
Eigenvalues — Definition & Finding
Definition A scalar \(\lambda\) is an eigenvalue of \(A\) if there exists a nonzero vector \(\mathbf{v}\) such that \(A\mathbf{v}=\lambda\mathbf{v}\). Such a \(\mathbf{v}\) is an eigenvector.
Procedure — Find All Eigenvalues
1
Set up the characteristic equation: \(\det(A-\lambda I)=0\).
2
Expand and solve this polynomial equation for \(\lambda\). The polynomial \(\det(A-\lambda I)\) is the characteristic polynomial of degree \(n\) for an \(n\times n\) matrix.
3
Shortcut for triangular matrices (all entries above or below diagonal = 0): eigenvalues are exactly the diagonal entries.
Example — Find Eigenvalues of \(A=\begin{bmatrix}1&2\\8&1\end{bmatrix}\) \[\det(A-\lambda I)=\det\begin{bmatrix}1-\lambda&2\\8&1-\lambda\end{bmatrix}=(1-\lambda)^2-16=\lambda^2-2\lambda-15=(\lambda-5)(\lambda+3)\] Eigenvalues: \(\lambda_1=5,\quad\lambda_2=-3\).
Eigenspaces — Finding Eigenvectors
Eigenspace Definition The eigenspace for eigenvalue \(\lambda\) is \(E_\lambda=\text{Nul}(A-\lambda I)\), i.e., all solutions to \((A-\lambda I)\mathbf{v}=\mathbf{0}\). It includes \(\mathbf{0}\) plus all eigenvectors for \(\lambda\). \[{\mathbf{v}\in E_\lambda}\iff A\mathbf{v}=\lambda\mathbf{v}\iff(A-\lambda I)\mathbf{v}=\mathbf{0}\iff\mathbf{v}\in\text{Nul}(A-\lambda I).\]
Example — Find Eigenvectors of \(A=\begin{bmatrix}1&2\\8&1\end{bmatrix}\) For \(\lambda_1=5\): Row-reduce \([A-5I\,|\,\mathbf{0}]=\begin{bmatrix}-4&2&0\\8&-4&0\end{bmatrix}\sim\begin{bmatrix}1&-\frac{1}{2}&0\\0&0&0\end{bmatrix}\). Free variable \(x_2=s\), so \(x_1=\frac{s}{2}\). Eigenvector: \(\begin{bmatrix}1\\2\end{bmatrix}\).

For \(\lambda_2=-3\): Row-reduce \([A+3I\,|\,\mathbf{0}]=\begin{bmatrix}4&2&0\\8&4&0\end{bmatrix}\sim\begin{bmatrix}1&\frac{1}{2}&0\\0&0&0\end{bmatrix}\). Eigenvector: \(\begin{bmatrix}1\\-2\end{bmatrix}\).
Key Theorems
Important Theorems
  • \(0\) is an eigenvalue of \(A\) \(\Leftrightarrow\) \(A\) is not invertible (det = 0).
  • Eigenvectors from distinct eigenvalues are always linearly independent.
  • If \(B=P^{-1}AP\), then \(A\) and \(B\) have the same eigenvalues (same characteristic polynomial). They are called similar.
  • If \(A\mathbf{v}=\lambda\mathbf{v}\), then \(A^k\mathbf{v}=\lambda^k\mathbf{v}\).
  • \(\det(AB)=\det(A)\det(B)\) and \(\det(A^T)=\det(A)\).
Diagonalization
Condition An \(n\times n\) matrix \(A\) is diagonalizable if and only if it has \(n\) linearly independent eigenvectors. This is guaranteed if \(A\) has \(n\) distinct eigenvalues (but not necessary — repeated eigenvalues may still work if eigenspaces are large enough).
4-Step Diagonalization Procedure
1
Find all eigenvalues by solving \(\det(A-\lambda I)=0\).
2
For each eigenvalue, find a basis for its eigenspace by row-reducing \([A-\lambda I\,|\,\mathbf{0}]\). You need \(n\) total LI eigenvectors across all eigenspaces.
3
Build \(P\): place the eigenvectors as columns (in any consistent order).
4
Build \(D\): diagonal matrix with eigenvalues in the same order as the corresponding eigenvectors in \(P\).
Key Identity & Power Formula \[A=PDP^{-1}\qquad\Rightarrow\qquad A^k=PD^kP^{-1}\] Since \(D\) is diagonal, \(D^k=\text{diag}(\lambda_1^k,\lambda_2^k,\ldots)\). Meaning: changing to the eigenvector basis makes the transformation just scaling along each axis.
Example — Diagonalizing \(A=\begin{bmatrix}1&2\\8&1\end{bmatrix}\) From above: \(\lambda_1=5\) with eigenvector \([1,2]^T\); \(\lambda_2=-3\) with eigenvector \([1,-2]^T\). \[P=\begin{bmatrix}1&1\\2&-2\end{bmatrix},\quad D=\begin{bmatrix}5&0\\0&-3\end{bmatrix},\quad A=PDP^{-1}.\]
Complex Eigenvalues (for Real Matrices)
Theorem When a real matrix has complex eigenvalues, they always come in conjugate pairs \(\lambda=a\pm bi\). The corresponding eigenvectors are also conjugates.
Rotation-Scaling Decomposition Any real \(2\times2\) matrix with complex eigenvalue \(\lambda=a+bi\) (\(b\neq0\)) can be written as \(A=PCP^{-1}\) where: \[C=\begin{bmatrix}a&-b\\b&a\end{bmatrix},\quad P=[\text{Re}\,\mathbf{v}\quad\text{Im}\,\mathbf{v}]\] (\(\mathbf{v}\) is an eigenvector for \(\lambda=a+bi\)). The matrix \(C\) encodes a rotation by angle \(\varphi=\arg(\lambda)\) combined with scaling by \(|\lambda|=\sqrt{a^2+b^2}\).

Euler: \(a+bi=re^{i\theta}\) where \(r=\sqrt{a^2+b^2}\) and \(\theta=\arctan(b/a)\). Complex multiplication: \((a+bi)(c+di)=(ac-bd)+(ad+bc)i\).

Past Exam — Projection Operator Eigenvalues Let \(V\) be a \(k\)-dimensional subspace of \(\mathbb{R}^n\). Let \(T(\mathbf{y})=\text{proj}_V\mathbf{y}\) with standard matrix \(A\).

Eigenvalues: If \(\mathbf{v}\in V\), then \(A\mathbf{v}=\mathbf{v}\), so \(\lambda=1\) is an eigenvalue with eigenspace \(V\) (dim \(k\)). If \(\mathbf{w}\perp V\), then \(A\mathbf{w}=\mathbf{0}\), so \(\lambda=0\) is an eigenvalue with eigenspace \(V^\perp\) (dim \(n-k\)).

Eigenvalues: \(\lambda=1\) (multiplicity \(k\)) and \(\lambda=0\) (multiplicity \(n-k\)).
Characteristic polynomial: \((-1)^n\lambda^{n-k}(\lambda-1)^k\).
Rank = \(k\); Nullity = \(n-k\). \(A\) is symmetric (projections onto subspaces always produce symmetric matrices).
Inner Products, Norms, Orthogonality
Key Definitions
  • Inner product: \(\mathbf{u}\cdot\mathbf{v}=u_1v_1+u_2v_2+\cdots+u_nv_n\)
  • Norm (length): \(\|\mathbf{v}\|=\sqrt{\mathbf{v}\cdot\mathbf{v}}\)
  • Normalizing: \(\hat{\mathbf{u}}=\dfrac{\mathbf{v}}{\|\mathbf{v}\|}\) gives a unit vector in the same direction.
  • Distance: \(\text{dist}(\mathbf{u},\mathbf{v})=\|\mathbf{u}-\mathbf{v}\|\)
  • Orthogonality: \(\mathbf{u}\cdot\mathbf{v}=0\iff\mathbf{u}\perp\mathbf{v}\iff\|\mathbf{u}+\mathbf{v}\|^2=\|\mathbf{u}\|^2+\|\mathbf{v}\|^2\) (Pythagorean theorem)
  • Cauchy-Schwarz: \(|\mathbf{u}\cdot\mathbf{v}|\leq\|\mathbf{u}\|\|\mathbf{v}\|\)
  • Triangle inequality: \(\|\mathbf{u}+\mathbf{v}\|\leq\|\mathbf{u}\|+\|\mathbf{v}\|\)
Orthogonal Sets & Matrices
Definitions
  • Orthogonal set: every pair of distinct vectors is orthogonal. If all nonzero → LI.
  • Orthonormal set: orthogonal set of unit vectors.
  • Orthogonal complement \(W^\perp\): set of all vectors orthogonal to every vector in \(W\).
  • Orthogonal matrix: square matrix with orthonormal columns → \(U^{-1}=U^T\) and \(\det U=\pm1\).
  • Orthonormal basis: a basis that is also orthonormal.
Properties of Orthogonal Matrices \(U\) If \(U\) has orthonormal columns, then \(U^TU=I\) and for any \(\mathbf{x},\mathbf{y}\): \[\|U\mathbf{x}\|=\|\mathbf{x}\|\quad(\text{preserves lengths}),\quad(U\mathbf{x})\cdot(U\mathbf{y})=\mathbf{x}\cdot\mathbf{y}\quad(\text{preserves dot products}),\quad U\mathbf{x}\perp U\mathbf{y}\iff\mathbf{x}\perp\mathbf{y}.\]
Fundamental Subspace Relationship For \(m\times n\) matrix \(A\): \[(\text{Row }A)^\perp=\text{Nul }A\qquad\text{and}\qquad(\text{Col }A)^\perp=\text{Nul }A^T.\]
Projections
Projection onto a Single Vector \(\mathbf{w}\) \[\text{proj}_{\mathbf{w}}\mathbf{v}=\frac{\mathbf{v}\cdot\mathbf{w}}{\mathbf{w}\cdot\mathbf{w}}\,\mathbf{w}=\frac{\langle\mathbf{v},\mathbf{w}\rangle}{\|\mathbf{w}\|^2}\,\mathbf{w}\]
Projection onto a Subspace \(W\) with Orthogonal Basis \(\{\mathbf{u}_1,\ldots,\mathbf{u}_k\}\) \[\text{proj}_W\mathbf{v}=\frac{\mathbf{v}\cdot\mathbf{u}_1}{\mathbf{u}_1\cdot\mathbf{u}_1}\mathbf{u}_1+\frac{\mathbf{v}\cdot\mathbf{u}_2}{\mathbf{u}_2\cdot\mathbf{u}_2}\mathbf{u}_2+\cdots+\frac{\mathbf{v}\cdot\mathbf{u}_k}{\mathbf{u}_k\cdot\mathbf{u}_k}\mathbf{u}_k\] If the basis is orthonormal: \(\text{proj}_W\mathbf{v}=(\mathbf{v}\cdot\mathbf{u}_1)\mathbf{u}_1+\cdots+(\mathbf{v}\cdot\mathbf{u}_k)\mathbf{u}_k=UU^T\mathbf{v}\) where columns of \(U\) are \(\mathbf{u}_i\).
Orthogonal Decomposition Every \(\mathbf{v}\in V\) can be written uniquely as \(\mathbf{v}=\mathbf{w}+\mathbf{w}^\perp\) where \(\mathbf{w}=\text{proj}_W\mathbf{v}\in W\) and \(\mathbf{w}^\perp\in W^\perp\). This gives the direct sum \(V=W\oplus W^\perp\). The projection \(\text{proj}_W\mathbf{v}\) is the closest vector in \(W\) to \(\mathbf{v}\).
QR Factorization (Gram-Schmidt)
Definition If \(A\) is \(m\times n\) with LI columns, then \(A=QR\) where \(Q\) is \(m\times n\) with orthonormal columns and \(R\) is \(n\times n\) upper triangular with positive diagonal entries. Since \(Q\) is orthogonal: \(R=Q^TA\).
Gram-Schmidt Procedure Given columns \(\mathbf{v}_1,\mathbf{v}_2,\mathbf{v}_3\) of \(A\):
1
Let \(\mathbf{u}_1=\mathbf{v}_1\).
2
\(\mathbf{u}_2=\mathbf{v}_2-\text{proj}_{\mathbf{u}_1}\mathbf{v}_2=\mathbf{v}_2-\dfrac{\mathbf{v}_2\cdot\mathbf{u}_1}{\mathbf{u}_1\cdot\mathbf{u}_1}\mathbf{u}_1\)
3
\(\mathbf{u}_3=\mathbf{v}_3-\text{proj}_{\mathbf{u}_1}\mathbf{v}_3-\text{proj}_{\mathbf{u}_2}\mathbf{v}_3\)
4
Normalize: \(\mathbf{q}_i=\mathbf{u}_i/\|\mathbf{u}_i\|\). Then \(Q=[\mathbf{q}_1\ \mathbf{q}_2\ \mathbf{q}_3]\).
5
Compute \(R=Q^TA\).
Example — QR of \(A\) with columns \(\mathbf{v}_1=[1,-1,0]^T,\;\mathbf{v}_2=[3,-3,1]^T,\;\mathbf{v}_3=[5,1,3]^T\) Step 1: \(\mathbf{u}_1=\mathbf{v}_1=[1,-1,0]^T\),\ \(\|\mathbf{u}_1\|^2=2\).

Step 2: \(\mathbf{v}_2\cdot\mathbf{u}_1=(3)(1)+(-3)(-1)+(1)(0)=6\).
\(\mathbf{u}_2=\mathbf{v}_2-\frac{6}{2}\mathbf{u}_1=[3,-3,1]-3[1,-1,0]=[0,0,1]^T\),\ \(\|\mathbf{u}_2\|^2=1\).

Step 3: \(\mathbf{v}_3\cdot\mathbf{u}_1=(5)(-1)+(1)(-1)=-6\ (\text{wait: }(5)(1)+(1)(-1)+(3)(0)=4)\). Actually: \(\mathbf{v}_3=[5,1,3]\), \(\mathbf{u}_1=[1,-1,0]\): \(\mathbf{v}_3\cdot\mathbf{u}_1=5-1+0=4\). And \(\mathbf{v}_3\cdot\mathbf{u}_2=(5)(0)+(1)(0)+(3)(1)=3\).
\(\mathbf{u}_3=\mathbf{v}_3-\frac{4}{2}\mathbf{u}_1-\frac{3}{1}\mathbf{u}_2=[5,1,3]-2[1,-1,0]-3[0,0,1]=[3,3,0]^T\).

Symmetric Matrices
Spectral Theorem for Symmetric Matrices An \(n\times n\) symmetric matrix \(A\) (i.e., \(A^T=A\)) must have:
  1. Exactly \(n\) real eigenvalues (counting multiplicities).
  2. Eigenspace dimension = algebraic multiplicity for each eigenvalue.
  3. Mutually orthogonal eigenspaces (eigenvectors from different eigenspaces are orthogonal).
  4. Must be orthogonally diagonalizable: \(A=PDP^T=PDP^{-1}\) with \(P\) orthogonal.
Orthogonal Diagonalization Procedure
4-Step Procedure
1
Find eigenvalues by solving \(\det(A-\lambda I)=0\).
2
Find eigenvector bases: for each \(\lambda\), find a basis for Nul\((A-\lambda I)\) by row-reducing \([A-\lambda I\,|\,\mathbf{0}]\).
3
Orthonormalize each eigenspace basis:
  • If multiplicity = 1: just normalize \(\mathbf{u}=\mathbf{v}/\|\mathbf{v}\|\).
  • If multiplicity > 1: apply Gram-Schmidt first, then normalize.
4
Construct \(P\) (orthonormal eigenvectors as columns) and \(D\) (eigenvalues in same order).
Spectral Decomposition
Formula A symmetric matrix \(A\) with eigenvalues \(\lambda_1,\ldots,\lambda_n\) and orthonormal eigenvectors \(\mathbf{u}_1,\ldots,\mathbf{u}_n\): \[A=\lambda_1\mathbf{u}_1\mathbf{u}_1^T+\lambda_2\mathbf{u}_2\mathbf{u}_2^T+\cdots+\lambda_n\mathbf{u}_n\mathbf{u}_n^T\] Each \(\mathbf{u}_j\mathbf{u}_j^T\) is a projection matrix (projects onto the direction of \(\mathbf{u}_j\)).
Quadratic Forms
Definition & Building Matrix A A quadratic form is \(Q(\mathbf{x})=\mathbf{x}^TA\mathbf{x}\) where \(A\) is symmetric. To build \(A\):
  • Place the coefficient of \(x_i^2\) in position \(A_{ii}\).
  • For cross-terms \(x_ix_j\): split the coefficient equally between \(A_{ij}\) and \(A_{ji}\).
Example: \(Q(\mathbf{x})=5x_1^2-4x_1x_2+5x_2^2\) → \(A=\begin{bmatrix}5&-2\\-2&5\end{bmatrix}\).
Principal Axes Theorem — Removing Cross-Products For any symmetric \(A\), there exists an orthogonal change of variable \(\mathbf{x}=P\mathbf{y}\) that transforms \(\mathbf{x}^TA\mathbf{x}\) into \(\mathbf{y}^TD\mathbf{y}=\lambda_1y_1^2+\lambda_2y_2^2+\cdots+\lambda_ny_n^2\) (no cross-products). The columns of \(P\) are the principal axes.
Example — Remove Cross-Products from \(Q(\mathbf{x})=5x_1^2-4x_1x_2+5x_2^2\)
1
Build \(A=\begin{bmatrix}5&-2\\-2&5\end{bmatrix}\).
2
Orthogonally diagonalize \(A\): \(\det(A-\lambda I)=(\lambda-3)(\lambda-7)=0\), so \(\lambda_1=3,\;\lambda_2=7\).
3
Find eigenvectors: \(\lambda_1=3\to\mathbf{u}_1=\frac{1}{\sqrt{2}}[1,1]^T\); \(\lambda_2=7\to\mathbf{u}_2=\frac{1}{\sqrt{2}}[1,-1]^T\).
\(P=\frac{1}{\sqrt{2}}\begin{bmatrix}1&1\\1&-1\end{bmatrix}\), \(D=\begin{bmatrix}3&0\\0&7\end{bmatrix}\).
4
New form: \(Q(\mathbf{y})=3y_1^2+7y_2^2\) (no cross-product!).

Singular Value Decomposition (SVD)
Definition For any \(m\times n\) matrix \(A\) with rank \(r\): \[A=U\Sigma V^T\] where \(U\) is \(m\times m\) orthogonal (columns = left singular vectors), \(V\) is \(n\times n\) orthogonal (columns = right singular vectors), and \(\Sigma\) is \(m\times n\) with diagonal \([\sigma_1,\ldots,\sigma_r,0,\ldots,0]\).
Singular Values The singular values \(\sigma_1\geq\sigma_2\geq\cdots\geq\sigma_r>0\) are the square roots of the nonzero eigenvalues of \(A^TA\) (= of \(AA^T\)), arranged in decreasing order.
SVD Procedure (Full)
1
Compute \(A^TA\) (an \(n\times n\) symmetric matrix).
2
Find eigenvalues \(\lambda_1\geq\lambda_2\geq\cdots\geq\lambda_n\geq0\) of \(A^TA\). Set \(\sigma_i=\sqrt{\lambda_i}\) for nonzero \(\lambda_i\).
3
Find orthonormal eigenvectors of \(A^TA\): \(\mathbf{v}_1,\ldots,\mathbf{v}_n\). These form the columns of \(V\).
4
For the first \(r\) columns of \(U\): \(\mathbf{u}_i=\dfrac{1}{\sigma_i}A\mathbf{v}_i\).
5
Extend \(\{\mathbf{u}_1,\ldots,\mathbf{u}_r\}\) to an orthonormal basis of \(\mathbb{R}^m\) using Gram-Schmidt (for the remaining \(m-r\) columns of \(U\)).
6
Assemble \(\Sigma\): \(m\times n\) zero matrix, then place \(\sigma_1,\ldots,\sigma_r\) on the diagonal.
Example — SVD of \(A=\begin{bmatrix}1&-1\\-2&2\\2&-2\end{bmatrix}\) (3×2) Step 1: \(A^TA=\begin{bmatrix}1&-2&2\\-1&2&-2\end{bmatrix}\begin{bmatrix}1&-1\\-2&2\\2&-2\end{bmatrix}=\begin{bmatrix}9&-9\\-9&9\end{bmatrix}\).

Step 2: \(\det(A^TA-\lambda I)=0\Rightarrow\lambda_1=18,\;\lambda_2=0\). So \(\sigma_1=\sqrt{18}=3\sqrt{2},\;\sigma_2=0\). Rank \(r=1\).

Step 3: For \(\lambda_1=18\): solve \((A^TA-18I)\mathbf{v}=0\Rightarrow\mathbf{v}_1=\frac{1}{\sqrt{2}}[1,-1]^T\).
For \(\lambda_2=0\): solve \(A^TA\mathbf{v}=0\Rightarrow\mathbf{v}_2=\frac{1}{\sqrt{2}}[1,1]^T\).
\(V=\frac{1}{\sqrt{2}}\begin{bmatrix}1&1\\-1&1\end{bmatrix}\).

Step 4: \(\mathbf{u}_1=\frac{1}{3\sqrt{2}}A\mathbf{v}_1=\frac{1}{3\sqrt{2}}\begin{bmatrix}1&-1\\-2&2\\2&-2\end{bmatrix}\frac{1}{\sqrt{2}}\begin{bmatrix}1\\-1\end{bmatrix}=\frac{1}{3\sqrt{2}}\cdot\frac{1}{\sqrt{2}}\begin{bmatrix}2\\-4\\4\end{bmatrix}=\begin{bmatrix}1/3\\-2/3\\2/3\end{bmatrix}\).

Step 5: Need 2 more columns for \(U\) (since \(m=3,\;r=1\)). Use Gram-Schmidt starting from a vector not parallel to \(\mathbf{u}_1\), e.g., \(\mathbf{e}_1=[1,0,0]^T\):
Orthogonalize against \(\mathbf{u}_1\): \(\mathbf{w}_2=[1,0,0]-\frac{1}{3}[1/3,-2/3,2/3]^T\cdot\ldots\) (proceed similarly). After normalization obtain \(\mathbf{u}_2\) and \(\mathbf{u}_3=\mathbf{u}_1\times\mathbf{u}_2\).

Step 6: \(\Sigma=\begin{bmatrix}3\sqrt{2}&0\\0&0\\0&0\end{bmatrix}\).

Spaces from SVD: Col\((A)\) = span of first \(r\) columns of \(U=\{\mathbf{u}_1\}\). Nul\((A^T)\) = last \(m-r\) columns of \(U\). Row\((A)\) = first \(r\) columns of \(V=\{\mathbf{v}_1\}\). Nul\((A)\) = last \(n-r\) columns of \(V=\{\mathbf{v}_2\}\).
Pseudoinverse & Best Rank-\(k\) Approximation Pseudoinverse: \(A^+=V_rD^{-1}U_r^T\) where \(V_r,U_r\) = first \(r\) columns of \(V,U\) and \(D=\text{diag}(\sigma_1,\ldots,\sigma_r)\).
Best rank-1 approximation: \(A_1=\sigma_1\mathbf{u}_1\mathbf{v}_1^T\) (minimizes \(\|A-B\|_F\) over all rank-1 matrices \(B\)).
Condition number (invertible \(n\times n\)): \(\kappa=\sigma_1/\sigma_n\). Large \(\kappa\) → ill-conditioned.
Converting Higher-Order ODEs to First-Order Systems
General Method For an \(n\)-th order ODE \(y^{(n)}=f(y,y',\ldots,y^{(n-1)})\): let \(x_1=y,\;x_2=y',\ldots,x_n=y^{(n-1)}\). Then \(\mathbf{x}'=A\mathbf{x}\).
Example — \(my''+ky=0\) Let \(x_1=y,\;x_2=y'\). Then \(x_1'=x_2\) and \(x_2'=y''=-\frac{k}{m}y=-\frac{k}{m}x_1\): \[\begin{bmatrix}x_1\\x_2\end{bmatrix}'=\begin{bmatrix}0&1\\-k/m&0\end{bmatrix}\begin{bmatrix}x_1\\x_2\end{bmatrix}\]
Example — Third-Order: \(y'''+3y''-y'-3y=0\) Let \(x_1=y,\;x_2=y',\;x_3=y''\). Then \(x_3'=y'''=-3y''+y'+3y=3x_1+x_2-3x_3\): \[\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}'=\begin{bmatrix}0&1&0\\0&0&1\\3&1&-3\end{bmatrix}\begin{bmatrix}x_1\\x_2\\x_3\end{bmatrix}\]

Case 1 — Distinct Real Roots
If \(r_1,r_2,\ldots,r_n\) are all distinct and real: \[y(t)=c_1e^{r_1t}+c_2e^{r_2t}+\cdots+c_ne^{r_nt}\]
Example — \(y''+5y'-6y=0\) Characteristic eq: \(r^2+5r-6=0\). Factor (or quadratic formula \(r=\frac{-b\pm\sqrt{b^2-4ac}}{2a}\)):

Wronskian — Testing Linear Independence of Solutions
Definition & Test For two solutions \(y_1,y_2\): the Wronskian is \[W[y_1,y_2](t)=\det\begin{bmatrix}y_1&y_2\\y_1'&y_2'\end{bmatrix}=y_1y_2'-y_1'y_2.\] If \(W(t)\neq0\) for any (equivalently, all) \(t\), then \(y_1\) and \(y_2\) are linearly independent (form a fundamental set).
Example — Are \(y_1=e^t\) and \(y_2=e^{-6t}\) independent? \[W=e^t(-6e^{-6t})-e^t\cdot e^{-6t}=-6e^{-5t}-e^{-5t}=-7e^{-5t}\neq0\text{ for all }t.\] Conclusion: \(y_1\) and \(y_2\) are linearly independent.

Procedure If \(r=\alpha\pm i\beta\) with eigenvector \(\mathbf{z}=\mathbf{a}+i\mathbf{b}\), two real solutions are: \[\mathbf{x}_1(t)=e^{\alpha t}(\cos(\beta t)\,\mathbf{a}-\sin(\beta t)\,\mathbf{b})\] \[\mathbf{x}_2(t)=e^{\alpha t}(\sin(\beta t)\,\mathbf{a}+\cos(\beta t)\,\mathbf{b})\] General solution: \(\mathbf{x}(t)=c_1\mathbf{x}_1(t)+c_2\mathbf{x}_2(t)\).
Example — \(A=\begin{bmatrix}-1&-1\\2&-3\end{bmatrix}\) Eigenvalues: \(\det(A-rI)=r^2+4r+5=0\Rightarrow r=-2\pm i\). So \(\alpha=-2,\;\beta=1\).

Eigenvector for \(r=-2+i\): Solve \((A-(-2+i)I)\mathbf{z}=0\): \[\begin{bmatrix}1-i&-1\\2&-1-i\end{bmatrix}\mathbf{z}=\mathbf{0}\] From row 1: \((1-i)z_1=z_2\). Let \(z_1=1\): \(z_2=1-i\). So \(\mathbf{z}=\begin{bmatrix}1\\1-i\end{bmatrix}=\begin{bmatrix}1\\1\end{bmatrix}+i\begin{bmatrix}0\\-1\end{bmatrix}\).
Thus \(\mathbf{a}=\begin{bmatrix}1\\1\end{bmatrix},\;\mathbf{b}=\begin{bmatrix}0\\-1\end{bmatrix}\).

Real solutions:
\(\mathbf{x}_1(t)=e^{-2t}\left(\cos t\begin{bmatrix}1\\1\end{bmatrix}-\sin t\begin{bmatrix}0\\-1\end{bmatrix}\right)=e^{-2t}\begin{bmatrix}\cos t\\\cos t+\sin t\end{bmatrix}\)
\(\mathbf{x}_2(t)=e^{-2t}\left(\sin t\begin{bmatrix}1\\1\end{bmatrix}+\cos t\begin{bmatrix}0\\-1\end{bmatrix}\right)=e^{-2t}\begin{bmatrix}\sin t\\\sin t-\cos t\end{bmatrix}\)

General solution: \(\mathbf{x}(t)=c_1\mathbf{x}_1(t)+c_2\mathbf{x}_2(t)\).
Repeated Eigenvalues — Generalized Eigenvectors
When Eigenspace is Too Small If \(\lambda\) has algebraic multiplicity 2 but eigenspace dimension 1 (only one LI eigenvector \(\mathbf{v}\)):
  • Solution 1: \(\mathbf{x}_1(t)=e^{\lambda t}\mathbf{v}\).
  • Find generalized eigenvector \(\mathbf{w}\) by solving \((A-\lambda I)\mathbf{w}=\mathbf{v}\).
  • Solution 2: \(\mathbf{x}_2(t)=e^{\lambda t}(t\mathbf{v}+\mathbf{w})\).
Past Exam — \(A=\begin{bmatrix}1&1&1\\0&1&1\\0&0&1\end{bmatrix}\), Find General Solution of \(\mathbf{x}'=A\mathbf{x}\) Eigenvalue: Triangular matrix, so \(\lambda=1\) (multiplicity 3).

Eigenspace: \(A-I=\begin{bmatrix}0&1&1\\0&0&1\\0&0&0\end{bmatrix}\). Row reduce: \(x_3=0\), \(x_2=0\), \(x_1\) free. Eigenvector: \(\mathbf{v}_1=[1,0,0]^T\). Only 1 eigenvector → not diagonalizable.

Generalized eigenvector (rank 2): Solve \((A-I)\mathbf{w}=\mathbf{v}_1=[1,0,0]^T\): \[\begin{bmatrix}0&1&1\\0&0&1\\0&0&0\end{bmatrix}\mathbf{w}=\begin{bmatrix}1\\0\\0\end{bmatrix}\] From row 2: \(w_3=0\); row 1: \(w_2+w_3=1\Rightarrow w_2=1\); \(w_1\) free (set 0). So \(\mathbf{w}_2=[0,1,0]^T\).

Generalized eigenvector (rank 3): Solve \((A-I)\mathbf{p}=\mathbf{w}_2=[0,1,0]^T\): \[\begin{bmatrix}0&1&1\\0&0&1\\0&0&0\end{bmatrix}\mathbf{p}=\begin{bmatrix}0\\1\\0\end{bmatrix}\] Row 2: \(p_3=1\); row 1: \(p_2+1=0\Rightarrow p_2=-1\); \(p_1\) free (set 0). So \(\mathbf{w}_3=[0,-1,1]^T\).

General solution (\(\lambda=1\), multiplicity 3): \[\mathbf{x}(t)=e^{t}\left[c_1\mathbf{v}_1+c_2(t\mathbf{v}_1+\mathbf{w}_2)+c_3\!\left(\frac{t^2}{2}\mathbf{v}_1+t\mathbf{w}_2+\mathbf{w}_3\right)\right]\]
Fundamental Matrix
Definition & IVP The fundamental matrix \(X(t)\) has linearly independent solutions as its columns. For IVP with \(\mathbf{x}(0)=\mathbf{x}_0\): \[\mathbf{x}(t)=X(t)\,X(0)^{-1}\,\mathbf{x}_0\]
Past Exam — Using a Given Fundamental Matrix Given \(X(t)=\begin{bmatrix}e^t&te^t\\0&e^t\end{bmatrix}\) and \(\mathbf{x}(0)=\begin{bmatrix}1\\1\end{bmatrix}\), find \(\mathbf{x}(1)\).

\(X(0)=\begin{bmatrix}1&0\\0&1\end{bmatrix}=I\Rightarrow X(0)^{-1}=I\).
\(\mathbf{x}(t)=X(t)\cdot I\cdot\begin{bmatrix}1\\1\end{bmatrix}=\begin{bmatrix}e^t+te^t\\e^t\end{bmatrix}\).
\(\mathbf{x}(1)=\begin{bmatrix}e+e\\e\end{bmatrix}=\begin{bmatrix}2e\\e\end{bmatrix}\).
Wronskian for Vector Functions
Test for Linear Independence For vector functions \(\mathbf{x}_1(t),\ldots,\mathbf{x}_n(t)\): compute \(W(t)=\det[\mathbf{x}_1(t)\ \cdots\ \mathbf{x}_n(t)]\). If \(W(t_0)\neq0\) for some \(t_0\), they are linearly independent on \((-\infty,\infty)\).
Example — LI of Three Vector Functions (Past Exam) \(\mathbf{x}_1=\begin{bmatrix}\sin x\\\sin x\end{bmatrix},\;\mathbf{x}_2=\begin{bmatrix}\sin x\\\cos x\end{bmatrix},\;\mathbf{x}_3=\begin{bmatrix}\cos x\\\cos x\end{bmatrix}\). At \(t=0\): \[W(0)=\det\begin{bmatrix}0&0&1\\0&1&1\end{bmatrix}\] For the \(3\times3\) case (with the three 2-vectors arranged as a \(2\times 3\) matrix — use the definition via assuming linear combination = 0 and testing at specific \(t\)): Suppose \(c_1\mathbf{x}_1+c_2\mathbf{x}_2+c_3\mathbf{x}_3=\mathbf{0}\). At \(t=\pi/2\): \(c_1\begin{bmatrix}1\\1\end{bmatrix}+c_2\begin{bmatrix}1\\0\end{bmatrix}+c_3\begin{bmatrix}0\\0\end{bmatrix}=\mathbf{0}\Rightarrow c_1+c_2=0,\;c_1=0\Rightarrow c_1=c_2=0\). Then at \(t=0\): \(c_3\begin{bmatrix}1\\1\end{bmatrix}=\mathbf{0}\Rightarrow c_3=0\). Linearly independent.
Even & Odd Functions
Even Functions: \(f(-x)=f(x)\) Examples: \(x^2,\;\cos x,\;|x|\), any constant.
\(\displaystyle\int_{-L}^{L}(\text{even})\,dx=2\int_0^L(\text{even})\,dx\)
Odd Functions: \(f(-x)=-f(x)\) Examples: \(x,\;x^3,\;\sin x\).
\(\displaystyle\int_{-L}^{L}(\text{odd})\,dx=0\)
Product Rules
  • even × even = even; odd × odd = even; even × odd = odd
  • \(f(x)\cdot\cos(nx)\): if \(f\) is odd → odd → integral over symmetric interval = 0.
  • \(f(x)\cdot\sin(nx)\): if \(f\) is even → odd... wait: \(\sin(nx)\) is odd, so even×odd = odd → integral = 0.
  • \(f(x)\cdot\cos(nx)\): even×even = even → integral may be nonzero.
Practical rules: In the Fourier cosine series (f extended evenly), all \(b_n=0\). In the Fourier sine series (f extended oddly), all \(a_n=0\).
General Fourier Series
Formula (Half-Period \(L\)) \[f(x)=\frac{a_0}{2}+\sum_{n=1}^{\infty}\left[a_n\cos\!\left(\frac{n\pi x}{L}\right)+b_n\sin\!\left(\frac{n\pi x}{L}\right)\right]\] where (for period \(2L\), i.e., \(f\) defined on \([-L,L]\)): \[a_0=\frac{1}{L}\int_{-L}^{L}f(x)\,dx,\qquad a_n=\frac{1}{L}\int_{-L}^{L}f(x)\cos\!\left(\frac{n\pi x}{L}\right)dx,\qquad b_n=\frac{1}{L}\int_{-L}^{L}f(x)\sin\!\left(\frac{n\pi x}{L}\right)dx.\] Note: When \(L=\pi\), \(\cos(n\pi x/L)=\cos(nx)\) and \(\sin(n\pi x/L)=\sin(nx)\).
Sine & Cosine Half-Range Series (function defined on \([0,L]\)) To get a sine series (odd extension): \(b_n=\dfrac{2}{L}\int_0^L f(x)\sin\!\left(\dfrac{n\pi x}{L}\right)dx\), all \(a_n=0\).

To get a cosine series (even extension): \(a_0=\dfrac{2}{L}\int_0^L f(x)\,dx\), \(a_n=\dfrac{2}{L}\int_0^L f(x)\cos\!\left(\dfrac{n\pi x}{L}\right)dx\), all \(b_n=0\).

• \(g(\pi/2)\): \(f\) is continuous there with \(f(\pi/2)=1\). So \(g(\pi/2)=1\).
• \(g(\pi)\): jump discontinuity (endpoint treated as average of left-limit \(f(\pi^-)=1\) and right-limit of next period \(f(-\pi^+)=0\)). So \(g(\pi)=\frac{1}{2}\). (c) Express \(g(\pi/2)\) as an infinite series:

Formula \[\int u\,dv=uv-\int v\,du\] Standard choices for Fourier computations:

Eigenvalues & Eigenvectors ★★★
Finding eigenvalues: solve det(A − λI) = 0
Finding eigenvectors for λ: row-reduce [A − λI | 0], express free vars
Eigenspace(A, λ) = Nul(A − λI) ⊇ all eigenvectors for λ
Key facts:
• λ = 0 is eigenvalue ⟺ A not invertible
• Triangular matrix: eigenvalues = diagonal entries
• Similar matrices: same char. poly., same eigenvalues
• Eigenvectors from distinct eigenvalues → LI
• If Av = λv, then Akv = λkv
• ⚠ Eigenspace dim ≤ algebraic multiplicity
Projection operator T(y) = projVy (dim V = k, space = ℝn):
Eigenvalues are 1 (mult = k) and 0 (mult = n−k)
A is symmetric; rank A = k; nullity A = n−k
Char. poly = λk(λ−1)n−k ... wait: λn−k(λ−1)k
Diagonalization ★★★
A = PDP−1: P = [eigvecs as cols], D = diag(eigenvalues, same order)
A diagonalizable iff A has n LI eigenvectors ⟺ dim(eigenspace for each λ) = algebraic multiplicity
⚠ n distinct eigenvalues → always diagonalizable
Algorithm:
Solve det(A − λI) = 0 → eigenvalues λi
For each λi, row-reduce [A − λiI | 0] → basis for eigenspace
Check: total # eigenvectors = n? (if not, not diagonalizable)
P = [v1 | v2 | … | vn], D = diag(λ1,…,λn)
3×3 triangular matrix A = [[2,h,0],[0,2,1],[0,0,3]]:
eigenvalues 2(×2), 3(×1). Diagonalizable ⟺ dim(eigenspace for λ=2) = 2 ⟺ A−2I has rank 1 ⟺ h = 0
Ak = PDkP−1 (fast powers)
Complex Eigenvalues & Generalized Eigenvectors ★★
2×2 real matrix, λ = a ± bi:
A = PCP−1, P = [Re(v) | Im(v)], C = [[a,−b],[b,a]]
(rotation by arg(λ) + scaling by |λ| = √(a²+b²))
Generalized eigenvectors (defective A):
If (A−λI) has repeated root but not enough eigenvectors:
Find v₁: (A−λI)v₁ = 0 (normal eigenvector)
Find v₂: (A−λI)v₂ = v₁ (generalized eigenvector)
Solutions to x' = Ax:
x₁ = eλtv₁,   x₂ = eλt(tv₁ + v₂)
Char poly of P₂ linear map example:
T(f) = t²f'' + f' + f, basis {1, t, t²}
T(1)=1, T(t)=t+1, T(t²)=2+t+t²
Matrix: [[1,1,2],[0,1,1],[0,0,1]] → eigenvalue λ=1 (×3)
Symmetric Matrices, Spectral Theorem & Quadratic Forms ★★★
Symmetric A = AT:
• All eigenvalues real
• Eigenvectors from different eigenspaces are orthogonal
• dim(eigenspace) = algebraic multiplicity
• Always orthogonally diagonalizable: A = PDPT
Orthogonal Diagonalization algorithm:
Find eigenvalues (char. eq.)
Find eigenspace basis for each λ
If eigenspace dim > 1: apply Gram-Schmidt within eigenspace
Normalize all eigenvectors
P = [normalized cols], D = diag(eigenvalues)
Spectral decomposition: A = λ₁u₁u₁T + … + λₙuₙuₙT
Quadratic form Q(x) = xTAx:
Build A: diagonal = coeff of xᵢ², off-diagonal = half coeff of xᵢxⱼ
E.g., x₁²+2x₁x₂+x₂² → A = [[1,1],[1,1]]
Classify by eigenvalues of A:
All λ > 0Positive definite
All λ < 0Negative definite
All λ ≥ 0Positive semidefinite
Mixed signsIndefinite
Change of variable x = Py transforms xTAx → yTDy (no cross-terms)
New form: λ₁y₁² + λ₂y₂² + … + λₙyₙ²
Singular Value Decomposition (SVD) ★★★
A = UΣVT: U (m×m orthogonal), Σ (m×n "diagonal"), V (n×n orthogonal)
σᵢ = singular values = √(eigenvalues of ATA), decreasing order
Compute S = ATA (symmetric n×n)
Find eigenvalues of S: λ₁ ≥ λ₂ ≥ … ≥ λₙ ≥ 0; σᵢ = √λᵢ
Find orthonormal eigenvectors v₁,…,vₙ of S → columns of V
For each σᵢ ≠ 0: uᵢ = (1/σᵢ)Avᵢ
Extend u's to orthonormal basis of ℝm (Gram-Schmidt if needed) → U
Σ: diagonal entries = σ₁, σ₂,… (remaining = 0)
Key facts from SVD:
• rank A = # nonzero singular values
• Col A: orthonormal basis = first r cols of U
• Nul A: orthonormal basis = last n−r cols of V
• Row A: orthonormal basis = first r cols of V
• Nul AT: last m−r cols of U
• Pseudoinverse: A⁺ = VᵣDᵣ⁻¹UᵣT
• Condition number: σ₁/σₙ
Best rank-k approximation: A ≈ σ₁u₁v₁T + … + σₖuₖvₖT (truncate SVD)
Orthogonality & Projections ★★★
Projection onto W with orthogonal basis {u₁,…,uₚ}:
ŷ = projWy = Σ (y·uᵢ/uᵢ·uᵢ)uᵢ
If {u₁,…,uₚ} orthonormal: ŷ = UUTy
Decomposition: y = ŷ + z, ŷ ∈ W, z ∈ W⊥ (unique)
Best Approx Theorem: ŷ is closest point in W to y
Orthogonal complement W⊥:
(Row A)⊥ = Nul A  |  (Col A)⊥ = Nul AT
V = W ⊕ W⊥  |  dim W + dim W⊥ = n
Orthogonal matrix U: U−1 = UT, ||Ux|| = ||x||, det U = ±1
Gram-Schmidt & QR ★★
Input: basis {x₁,…,xₚ} for W
Output: orthogonal basis {v₁,…,vₚ}
v₁ = x₁
v₂ = x₂ − (x₂·v₁/v₁·v₁)v₁
v₃ = x₃ − (x₃·v₁/v₁·v₁)v₁ − (x₃·v₂/v₂·v₂)v₂
Normalize: uᵢ = vᵢ/||vᵢ||
QR Factorization (A = m×n, LI cols):
Q = m×n with orthonormal cols (from G-S on cols of A)
R = n×n upper triangular, positive diag entries
R = QTA (since QTQ = I)
Span preserved: Span{v₁,…,vₖ} = Span{x₁,…,xₖ} at each step
Least Squares ★★★
Problem: Ax = b has no solution; find x̂ minimizing ||b − Ax||
Normal equations: ATAx̂ = ATb
If cols of A are LI: x̂ = (ATA)−1ATb
Via QR: x̂ = R−1QTb
Least-squares line y = β₀ + β₁x through data (xᵢ, yᵢ):
Build X = [[1, x₁],[1, x₂],…,[1, xₙ]], y = [y₁,…,yₙ]
Solve XTXβ = XTy for β = [β₀, β₁]
Nul(ATA) = Nul A (key identity for proofs)
rank(ATA) = rank(A)
Linear Transformations & Change of Basis ★★
Matrix of T: V→W relative to bases B, C:
M = [[T(b₁)]C | [T(b₂)]C | … | [T(bₙ)]C]
Then [T(x)]C = M[x]B
Change of basis PC←B: col j = [bⱼ]C
To find: row reduce [C | B] → [I | PC←B]
PB←C = (PC←B)−1
Standard matrix of T: ℝⁿ→ℝᵐ: A = [T(e₁) | T(e₂) | … | T(eₙ)]
T one-to-one ⟺ cols LI ⟺ Nul T = {0}
T onto ⟺ cols span ℝᵐ
P₂ basis {1, t, t²}: represents polynomials as 3-vectors
dim Pₙ = n+1, basis {1, t, t², …, tⁿ}
Subspaces, Rank-Nullity, Key Spaces
Rank-Nullity: rank A + nullity A = n (# cols)
rank A = dim Col A = # pivots; nullity A = # free vars
Col A / Img / Rangespan of cols; subset of ℝᵐ
Nul A / Kersolns to Ax=0; subset of ℝⁿ
Row Aspan of rows; subset of ℝⁿ
A² = 0: Col A ⊆ Nul A → rank A ≤ n/2
AT = −A (skew-symmetric): real eigenvalues = 0; eAt orthogonal
Invertible Matrix Theorem (key equivalences):
A invertible ⟺ det A ≠ 0 ⟺ n pivots ⟺ Ax=0 trivial soln ⟺ cols LI ⟺ cols span ℝⁿ ⟺ AT invertible
Integer matrix: det A = ±1 ⟺ A−1 has integer entries (use adj formula)
Determinants & Invertibility
Row swapdet → −det
Scale row by kdet → k·det
Add multiple of rowdet unchanged
det(kA) n×nkⁿ·det(A)
det(AB)det(A)·det(B)
det(AT)det(A)
det(A−1)1/det(A)
Triangular Aproduct of diagonal
2×2 inverse: A = [[a,b],[c,d]], A−1 = (1/(ad−bc))[[d,−b],[−c,a]]
Adjugate: A−1 = (1/det A) adj A, (adj A)ᵢⱼ = Cⱼᵢ
Cramer's Rule: xᵢ = det Aᵢ(b) / det A
── Differential Equations ──
2nd Order Homogeneous ODE ★★★
ay'' + by' + cy = 0 → char. eq: ar² + br + c = 0
2 distinct real r₁, r₂y = c₁e^{r₁t} + c₂e^{r₂t}
Repeated root ry = c₁e^{rt} + c₂te^{rt}
Complex α ± βiy = e^{αt}(c₁cos(βt) + c₂sin(βt))
Apply IVP: y(t₀)=Y₀, y'(t₀)=Y₁ → differentiate y(t), plug in t₀
Wronskian: W(y₁,y₂) = y₁y₂'−y₁'y₂ ≠ 0 ⟹ LI
⚠ W=0 at one point ⟹ LD (for solns of same ODE)
Method of Undetermined Coefficients ★★★
For ay''+by'+cy = f(t):
Find yₚ then y = yh + yₚ
f(t) = Ctᵐe^{rt}:   guess yₚ = tˢ(Aₘtᵐ+…+A₀)e^{rt}
r not a roots = 0
r is simple roots = 1
r is double roots = 2
f(t) = Ctᵐe^{αt}cos/sin(βt), β≠0:
guess yₚ = tˢe^{αt}[(Aₘtᵐ+…+A₀)cos(βt) + (Bₘtᵐ+…+B₀)sin(βt)]
s=0 if α+iβ not a root; s=1 if it is
y''+2y'+y = e−t: char eq (r+1)²=0, r=−1 double root. r=−1 matches, m=0 → yₚ = t²Ae−t
Variation of Parameters & 3rd Order
ay''+by'+cy = f(t), known y₁,y₂:
yₚ = u₁y₁ + u₂y₂ where:
u₁' = −y₂(f/a)/W,   u₂' = y₁(f/a)/W
W = y₁y₂'−y₁'y₂ (Wronskian)
Nonhom. general solution:
y(t) = yₚ + c₁y₁ + c₂y₂
(unique soln for any IVP by existence/uniqueness)
Superposition: if y₁ solves Ly=f₁, y₂ solves Ly=f₂,
then k₁y₁+k₂y₂ solves Ly = k₁f₁+k₂f₂
3rd order y'''+ay''+by'+cy = f:
Same logic; char. eq cubic r³+ar²+br+c=0
3 roots → 3 terms in yh
Systems of ODEs: x'(t) = Ax(t) ★★★
Converting nth order ODE to system:
y''+py'+qy = 0: let x₁=y, x₂=y'
x₁' = x₂
x₂' = −qx₁−px₂
A = [[0, 1],[−q, −p]]
(for y''+3y'+2y=0: A=[[0,1],[−2,−3]])
n distinct real eigenvalues r₁,…,rₙ with eigenvectors u₁,…,uₙ:
x(t) = c₁e^{r₁t}u₁ + … + cₙe^{rₙt}uₙ
Fundamental matrix: X(t) = [e^{r₁t}u₁ | … | e^{rₙt}uₙ]
Solving IVP x(0) = x₀:
x₀ = c₁u₁ + … + cₙuₙ
Row reduce [u₁|…|uₙ|x₀] to find c's
OR: x(t) = X(t)X(0)⁻¹x₀
Complex eigenvalues α±iβ, eigenvector a±ib:
Two real solutions:
x₁ = e^{αt}(cos(βt)a − sin(βt)b)
x₂ = e^{αt}(sin(βt)a + cos(βt)b)
Repeated eigenvalue r, defective:
Find v₁ (eigenvec), v₂ s.t. (A−rI)v₂=v₁
x₁ = e^{rt}v₁
x₂ = e^{rt}(tv₁ + v₂)
Given fundamental matrix X(t), IVP x(0)=x₀:
x(t) = X(t)·X(0)⁻¹·x₀
E.g. X(0) = [[e⁰, 0·e⁰],[0, e⁰]] = I → x(t) = X(t)x₀
Linear independence of vector solutions: compute Wronskian W(t)=det[x₁(t)|x₂(t)|…] at convenient t (e.g. t=0). W≠0 ⟹ LI on (−∞,∞).
Check at t=0 for vectors like [sinx/sinx], [sinx/cosx], [cosx/cosx]: form matrix, compute det; if ≠0 → LI.
Fourier Series ★★★
Full Fourier on [−L, L]:
f(x) = a₀/2 + Σ[aₙcos(nπx/L) + bₙsin(nπx/L)]
aₙ = (1/L)∫₋ₗᴸ f(x)cos(nπx/L)dx
bₙ = (1/L)∫₋ₗᴸ f(x)sin(nπx/L)dx
Fourier Cosine Series on [0, L]:
f(x) = a₀/2 + Σ aₙcos(nπx/L)
aₙ = (2/L)∫₀ᴸ f(x)cos(nπx/L)dx
(extend f as even to [−L,L])
Fourier Sine Series on [0, L]:
f(x) = Σ bₙsin(nπx/L)
bₙ = (2/L)∫₀ᴸ f(x)sin(nπx/L)dx
(extend f as odd to [−L,L])
Convergence (Dirichlet):
At continuity point: series → f(x)
At jump discontinuity x₀: → ½[f(x₀⁺) + f(x₀⁻)]
At endpoints (periodic extension): → ½[f(L⁻)+f(−L⁺)]
Even/odd shortcuts:
f even ⟹ bₙ = 0 (use cosine series)
f odd ⟹ aₙ = 0 (use sine series)
f(x)·cos(nx): even·even=even or odd·even=odd
⚠ ∫odd on [−L,L] = 0
Useful: f(x)=1 on [0,π], 0 on [−π,0], L=π:
a₀=1, aₙ=0, bₙ=2/(nπ)(1−cos(nπ))=(2/nπ) for n odd
At x=0: g(0)=½; at x=π/2: g(π/2)=1; at x=π: g(π)=½
→ series at π/2 gives: 1 = ½ + (2/π)(1 − 1/3 + 1/5−…) → Leibniz formula
Integration by Parts (Fourier Integrals)
∫u dv = uv − ∫v du
∫x·sin(nx)dx: u=x, dv=sin(nx)dx → v=−cos(nx)/n
= −x·cos(nx)/n + ∫cos(nx)/n dx = −x·cos(nx)/n + sin(nx)/n²
∫x·cos(nx)dx: u=x, dv=cos(nx)dx → v=sin(nx)/n
= x·sin(nx)/n − ∫sin(nx)/n dx = x·sin(nx)/n + cos(nx)/n²
Key values: sin(nπ)=0, cos(nπ)=(−1)ⁿ
sin(nπ/2): 0,1,0,−1,0,1,… for n=0,1,2,3,4,5,…
Trig identities:
sin²A+cos²A=1  |  sin(2A)=2sinAcosA
cos(2A)=2cos²A−1=1−2sin²A
sin(A±B)=sinAcosB±cosAsinB
cos(A±B)=cosAcosB∓sinAsinB
Common Pitfalls & Exam Tricks
Undetermined coefficients: always check if r matches a root before guessing yₚ — multiply by tˢ!
Projection eigenvalues: T = projV ⟹ λ=1 (on V) and λ=0 (on V⊥). A² = A (idempotent).
Wronskian for vector fns: evaluate at t=0 for simplicity
SVD Σ dimensions: if A is m×n, Σ is m×n (not square!)
Orthogonal diagonalization: for sym matrices, eigenvectors from same eigenspace need G-S; from different eigenspaces are auto-orthogonal
LI of [sinx/sinx], [sinx/cosx], [cosx/cosx]: at x=0 gives det([[0,0,1],[0,1,0],[1,1,1]])... actually evaluate det carefully
Least squares line: always set up X = [1's col | x-values col], don't forget the 1's column
General soln = homogeneous + particular: never forget c₁y₁+c₂y₂ term
det for 3×3: cofactor along simplest row/col (most zeros)
⚠ ATA ≠ AAT in general; SVD uses ATA for V, AAT for U directly
Proof Toolbox (Exam Proofs)
Nul(ATA) = Nul A: x ∈ Nul(ATA) → ATAx=0 → xTATAx=0 → ||Ax||²=0 → Ax=0 → x ∈ Nul A. Converse: Ax=0 → ATAx=0.
Col A ⊆ Nul A (given A²=0): let b=Av ∈ Col A; then Ab=A(Av)=A²v=0 → b ∈ Nul A
eAt orthogonal (given AT=−A): show (eAt)TeAt=I. Use that d/dt[(eAt)TeAt] = 0.
λ real eigenvalue of T, T(v)·u = −v·T(u): T(v)=λv → T(v)·v=λ(v·v) and −v·T(v)=−λ(v·v) → 2λ||v||²=0 → λ=0
Wronskian ≠ 0 ⟹ LI: if c₁f+c₂g=0 for all x, differentiate → system with Wronskian det ≠ 0 → only trivial soln
Integer det ±1 ⟹ A−1 integer: A−1 = (1/det A)adj A; adj A has integer entries (cofactors = integer combos of integer entries); det A = ±1 → no fractions
Linear Independence Rules
Set contains 0→ LD
Two vectors, one scalar mult of other→ LD
More vectors than dimension→ LD
Pivot in every column→ LI
Square + LI⟺ spanning ⟺ invertible
Check LI: form matrix with vectors as cols, row reduce; LI ⟺ no free vars
Span ℝⁿ: pivot in every row
Subspace check: contains 0? closed under + and ·?
Basis: LI + spanning; Unique Representation Thm
Key Theorems Summary
Existence-Uniqueness (ODE): ay''+by'+cy=f with IVP has unique soln
Rank Theorem: rank + nullity = # cols
Basis Theorem: p-dim space: any p LI vectors = basis; any p spanning vectors = basis
Spectral (Sym.): n real eigenvalues (w/ mult), eigenspaces mutually ⊥, orthogonally diagonalizable
Best Approx: ŷ = projWy is closest point in W to y
Orthog. Decomp: y = ŷ + z uniquely, ŷ ∈ W, z ∈ W⊥
SVD existence: every m×n matrix has SVD
Cauchy-Schwarz: |⟨u,v⟩| ≤ ||u||·||v||
Quick Computation Reference
2×2 det: ad−bc
3×3 char poly: expand det(A−λI) by cofactors along col/row with most structure
Projection formula (single vector u):
projuv = (v·u/u·u)u

||v||²: = v·v = v₁²+…+vₙ²
Unit vector: u = v/||v||

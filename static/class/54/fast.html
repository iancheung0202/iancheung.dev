HOT Ch2 Linear Transformations — T, Kernel, Image, Injectivity, Surjectivity ▶
T is Linear iff ALL THREE hold
1. T(u+v) = T(u)+T(v)
2. T(cu) = cT(u)
3. T(0) = 0 [implied by 2, but verify]
To get matrix [T]: compute T(e₁), T(e₂),… and place as columns
[T] = [ T(e₁) | T(e₂) | … ]
Kernel & Image
Ker(T) = Nul(A) = solutions to Ax=0
= {v ∈ V | T(v) = 0}
Img(T) = Col(A) = span of columns of A
= {T(v) | v ∈ V}

Linear Subspace Test
V₀ ⊆ V₁ is a subspace iff:
1. 0 ∈ V₀ (non-empty)
2. Closed under scalar mult: u∈V₀ ⟹ cu∈V₀
3. Closed under addition: u,v∈V₀ ⟹ u+v∈V₀
Must check ALL three. A single failure means NOT a subspace.
Ch3 Determinants — Properties, Cofactor Expansion, Row Ops ▶
Row Operation Effects on det
  • Row swap → det multiplied by −1
  • Scale row by k → det multiplied by k
  • Add multiple of row to another → det unchanged
  • Scale whole n×n matrix by k → det(kA) = kⁿ·det(A)
det(AB) = det(A)·det(B)
det(Aᵀ) = det(A)
det(A⁻¹) = 1/det(A)
Special Cases
Triangular matrix: det = product of diagonal
Orthogonal matrix: det = ±1
|det(A)| = area (ℝ²) or volume (ℝ³) of parallelogram/piped
If det(A)=±1 and A has integer entries, A⁻¹ also has integer entries.
2×2 Inverse Formula
A = [a b; c d]
A⁻¹ = 1/(ad−bc) · [d −b; −c a]
Invertible iff ad−bc ≠ 0
Cramer's Rule: xᵢ = det(Aᵢ(b)) / det(A)
where Aᵢ(b) = A with col i replaced by b
Invertible Matrix Theorem (all equiv)
  • A invertible
  • det(A) ≠ 0
  • n pivot positions
  • Ax=0 has only trivial solution
  • Columns are LI
  • Columns span ℝⁿ
  • Aᵀ is invertible
  • A has n nonzero singular values
Proving integer-entry inverse (Exam Q2 type)
Exam-Style Proof
If A and A⁻¹ both have integer entries, prove det(A) = ±1
• A·A⁻¹ = I → det(A)·det(A⁻¹) = det(I) = 1
• Both det(A) and det(A⁻¹) are integers (integer entries, det is integer combination)
• Two integers multiplying to 1 → each is ±1
∴ det(A) = ±1 ∎
Converse: If A has integer entries and det(A)=±1, then A⁻¹ has integer entries
• A⁻¹ = (1/det A)·adj(A)
• adj(A) has integer entries (cofactors = signed minors of integer matrix)
• 1/det(A) = 1/(±1) = ±1, so A⁻¹ = ±adj(A) → integer entries ∎
HOT Ch4 Col/Null Space, Rank, Nullity, Basis — Finding Everything ▶
Key Vocabulary
Col(A) = Img(A) = Range(A)
All linear combos of cols of A (output space)
Nul(A) = Ker(A)
All x where Ax=0 (input space)
Rank(A) = dim(Col A) = # pivot cols
Nullity(A) = dim(Nul A) = # free vars
Rank-Nullity Theorem
rank(A) + nullity(A) = n
where n = # columns = dim(domain)
Also: Rank(T) + Nullity(T) = dim(V) for T: V→W
Don't confuse n (cols) with m (rows)! Rank ≤ min(m,n)
Orthogonal Complements
(Row A)⊥ = Nul A
(Col A)⊥ = Nul Aᵀ
dim(W) + dim(W⊥) = n
W ⊕ W⊥ = ℝⁿ
How to Find Basis for Col(A)
  1. 1Row reduce A to REF/RREF
  2. 2Identify pivot columns in REF
  3. 3Take those same column indices from original A
Use original A columns, NOT the RREF columns!
How to Find Basis for Nul(A)
  1. 1Row reduce [A | 0] to RREF
  2. 2Write free variables parametrically
  3. 3Express x = x_f1·v1 + x_f2·v2 + …
  4. 4The vectors {v1, v2, …} form the basis
Polynomial Space Pₙ
Pₙ behaves like vectors. dim(Pₙ) = n+1. Basis = {1, x, x², …, xⁿ}
e.g. P₂ has basis {1, t, t²} and dimension 3
Ch4 Change of Basis — Coordinates, P_C←B Matrix ▶
Finding New Coordinates
Given v = [a,b] in old basis {e₁,e₂}
New basis B' = {e₁', e₂'}
Solve: [e₁' e₂'] [x,y]ᵀ = [a,b]ᵀ

  2. 2Row reduce to [I | P]
  3. 3P = P_{C←B}
P_{C←B}⁻¹ = P_{B←C}
If b₁=4c₁+c₂, b₂=−6c₁+c₂ then P=[4 −6 \ 1 1] (read off coefficients as columns)

HOT Ch5 Eigenvalues & Eigenvectors — Full Procedure ▶
Core Definitions
Av = λv, v ≠ 0
λ = eigenvalue, v = eigenvector
λ is eigenvalue iff det(A−λI) = 0
(characteristic equation)
Eigenspace(A,λ) = Nul(A−λI)
= {all eigenvectors for λ} ∪ {0}
Step-by-Step: Finding Eigenvalues + Eigenvectors
  1. 1Set up det(A−λI)=0 and expand → characteristic polynomial
  2. 2Factor to find λ values
  3. 3For each λ, row reduce [A−λI | 0]
  4. 4Express solution with free variables → eigenvectors
  5. 5Basis for eigenspace = free parameter vectors
Triangular matrix: eigenvalues = diagonal entries. No work needed!
Key Theorems
  • 0 is eigenvalue ⟺ A is NOT invertible
  • Eigenvectors from distinct eigenvalues are LI
  • If Av=λv then Aᵏv = λᵏv
  • A and B=P⁻¹AP have same eigenvalues
  • Similar matrices: same char. poly.
Recognition Patterns
🔍 Is λ an eigenvalue?
Check det(A−λI)=0. Yes/No.
🔍 Is v an eigenvector?
Compute Av. If Av = cv for some scalar c, then v is eigenvector with eigenvalue c.
🔍 Eigenvalues of Aᵏ?
Same eigenvectors, eigenvalues become λᵏ.

HOT Ch5 Diagonalization — Full Algorithm + Conditions ▶
Diagonalizable iff…
  • A has n LI eigenvectors
  • OR A has n distinct eigenvalues
  • OR for each λₖ: geometric mult = algebraic mult
Having n distinct eigenvalues ⟹ diagonalizable. But NOT every diagonalizable matrix has distinct eigenvalues (repeated roots can still work if eigenspaces are big enough).
How to Diagonalize
  1. 1Find all eigenvalues: solve det(A−λI)=0
  2. 2For each λ, find basis for eigenspace (Nul(A−λI))
  3. 3Check: total # of LI eigenvectors = n?
  4. 4Build P: eigenvectors as columns (order matters!)
  5. 5Build D: matching eigenvalues on diagonal
A = PDP⁻¹ → Aᵏ = PDᵏP⁻¹
Dᵏ is trivial: just raise each diagonal entry to the kth power.
Diagonalizability Condition (Exam Q1 type)
Past Exam Q1 — Condition on h

Triangular → eigenvalues = diagonal = 2 (double), 3 (simple)
λ=3 always gives 1D eigenspace ✓
λ=2 (alg. mult=2): need geometric mult = 2 → need 2 LI eigenvectors
A−2I = [0 h 0; 0 0 1; 0 0 1] → RREF: [0 h 0; 0 0 1; 0 0 0]
If h≠0: only 1 free variable → eigenspace dim=1 < 2 → NOT diagonalizable
A is diagonalizable iff h = 0
Geometric vs Algebraic Multiplicity
Algebraic mult = power of (λ−λₖ) in char poly
Geometric mult = dim(Eigenspace) = dim(Nul(A−λI))
Always: geometric ≤ algebraic
Diagonalizable iff for ALL λₖ: geometric = algebraic

For 2×2 with λ = a−bi (b≠0), eigenvector v = Re(v)+i·Im(v):

Ch6 Core Orthogonality — Definitions + Properties ▶
Fundamental Definitions
‖v‖ = √(v·v)
Normalize: û = v/‖v‖
dist(u,v) = ‖u−v‖
Orthogonal: u·v = 0
‖u+v‖² = ‖u‖²+‖v‖² iff u⊥v (Pythagorean)
Cauchy-Schwarz: |u·v| ≤ ‖u‖‖v‖
Triangle: ‖u+v‖ ≤ ‖u‖+‖v‖
Orthogonal Sets → Matrices
Orthogonal set: each pair u·v=0
If nonzero → automatically LI
Orthonormal set: orthogonal + unit vectors
Orthogonal matrix U: square, orthonormal cols
U⁻¹ = Uᵀ, det(U)=±1
UᵀU = I
If U has orthonormal cols:
‖Ux‖=‖x‖, (Ux)·(Uy)=x·y
Orthogonal Complement
W⊥ = all v ∈ ℝⁿ with v·w=0 for all w∈W
Always a subspace
(Row A)⊥ = Nul A
(Col A)⊥ = Nul Aᵀ
V = W ⊕ W⊥ (direct sum)
dim(W) + dim(W⊥) = n
W ∩ W⊥ = {0}
HOT Ch6 Orthogonal Projections — Onto Vector, Onto Subspace ▶
Projection onto a Single Vector w
proj_w(v) = (v·w)/(w·w) · w
Component of v orthogonal to w:
z = v − proj_w(v)
If w is unit vector: proj_w(v) = (v·w)·w (no denominator needed)
Projection onto Subspace W
For orthogonal basis {u₁,…,uₚ} of W:
proj_W(v) = Σ (v·uᵢ)/(uᵢ·uᵢ) · uᵢ
For orthonormal basis: proj_W(v) = UUᵀv
where U = [u₁ … uₚ]
Best Approximation Theorem: proj_W(v) is the CLOSEST point in W to v. ‖v−proj_W(v)‖ is minimized.

1. Using non-orthogonal basis without Gram-Schmidt first — projection formula only works with orthogonal basis!

HOT Ch6 Gram-Schmidt Process + QR Factorization ▶
Gram-Schmidt Algorithm
Input: {x₁, x₂, …, xₚ} basis for W
  1. 1v₁ = x₁
  2. 2v₂ = x₂ − (x₂·v₁)/(v₁·v₁)·v₁
  3. 3v₃ = x₃ − (x₃·v₁)/(v₁·v₁)·v₁ − (x₃·v₂)/(v₂·v₂)·v₂
  4. 4vₖ = xₖ − Σᵢ₌₁ᵏ⁻¹ (xₖ·vᵢ)/(vᵢ·vᵢ)·vᵢ
  5. 5Normalize: uᵢ = vᵢ/‖vᵢ‖
Result: {v₁,…,vₚ} orthogonal basis
{u₁,…,uₚ} orthonormal basis
Span{v₁,…,vₖ} = Span{x₁,…,xₖ} ∀k
QR Factorization
A = QR where:
Q = m×n matrix with orthonormal cols
R = n×n upper triangular, invertible, positive diagonal
  1. 1Extract columns of A (v₁, v₂, …)
  2. 2Apply Gram-Schmidt → orthonormal {u₁, u₂, …}
  3. 3Q = [u₁ u₂ …]
  4. 4R = QᵀA (since Q orthonormal)
Least squares via QR: x̂ = R⁻¹Qᵀb

HOT Ch7 Symmetric Matrices + Orthogonal Diagonalization ▶
Symmetric Matrix Properties
A = Aᵀ (symmetric)
Key theorem (Spectral Theorem):
• n real eigenvalues (counting mult)
• Eigenspace dim = algebraic mult
• Eigenspaces mutually orthogonal
• Always orthogonally diagonalizable
Symmetric ⟺ orthogonally diagonalizable (both directions!)
How to Orthogonally Diagonalize
  1. 1Find eigenvalues via det(A−λI)=0
  2. 2For each λ, find basis for Nul(A−λI)
  3. 3If mult=1: just normalize eigenvector
  4. 4If mult>1: apply Gram-Schmidt first, then normalize
  5. 5P = [u₁|…|uₙ] (orthonormal eigenvectors)
  6. 6D = diag(λ₁,…,λₙ) matching order
A = PDPᵀ = PDP⁻¹
Eigenvectors from DIFFERENT eigenspaces are automatically orthogonal. Only need GS within same eigenspace!
Spectral Decomposition
A = λ₁u₁u₁ᵀ + λ₂u₂u₂ᵀ + … + λₙuₙuₙᵀ
uᵢuᵢᵀ = "projection matrix" onto eigenspace of λᵢ
Each uᵢuᵢᵀ is rank-1. The spectral decomposition shows A as sum of rank-1 pieces scaled by eigenvalues.
HOT Ch7 Quadratic Forms — Classification + Change of Variables ▶
Building Matrix A from Q(x)
Q(x) = xᵀAx, A symmetric
• Coefficient of xᵢ² → Aᵢᵢ
• Coefficient of xᵢxⱼ → split evenly: Aᵢⱼ = Aⱼᵢ = (coeff)/2
Q(x) = 5x₁²−4x₁x₂+5x₂²
A₁₁=5, A₂₂=5, A₁₂=A₂₁=−4/2=−2
A=[5 −2; −2 5]
Q(x) = x₁²+2x₁x₂+x₂² (Past Exam Q5)
A₁₁=1, A₂₂=1, A₁₂=A₂₁=1
A=[1 1; 1 1]

Change of Variables (Remove Cross-Products)
  1. 1Build symmetric matrix A from Q
  2. 2Orthogonally diagonalize A: find λᵢ and orthonormal uᵢ
  3. 3Set P=[u₁ … uₙ], D=diag(λ₁,…,λₙ)
  4. 4Substitute x=Py → Q(y) = λ₁y₁²+λ₂y₂²+…
Q(x)=5x₁²−4x₁x₂+5x₂² → remove cross-product
A=[5 −2;−2 5], eigenvalues: det(A−λI)=(5−λ)²−4=0 → λ=3,7
Eigenvectors: λ=3→[1;1]/√2, λ=7→[1;−1]/√2
Q(y) = 3y₁²+7y₂² (no cross-products!)
Common Mistake
The cross-product coefficient must be SPLIT evenly between Aᵢⱼ and Aⱼᵢ. e.g., Q=x₁x₂ → A₁₂=A₂₁=1/2, NOT A₁₂=1.
EXAM Ch7 Singular Value Decomposition (SVD) — Full Algorithm ▶
SVD Setup & Vocabulary
A = UΣVᵀ
U: m×m orthogonal (left singular vectors)
V: n×n orthogonal (right singular vectors)
Σ: m×n "diagonal" (singular values on diag)
Singular values = √(eigenvalues of AᵀA)
σᵢ = √λᵢ, arranged decreasing
A⁺ = VᵣD⁻¹Uᵣᵀ (pseudoinverse)
SVD Algorithm
  1. 1Compute AᵀA (n×n symmetric)
  2. 2Find eigenvalues of AᵀA (det(AᵀA−λI)=0)

Wronskian ≠ 0 ⟹ LI (Past Exam Q5)
Prove: W[f,g](x₀)≠0 ⟹ f,g LI
Suppose c₁f+c₂g=0 for all x. Differentiate: c₁f'+c₂g'=0.
At x₀: [f(x₀) g(x₀); f'(x₀) g'(x₀)][c₁;c₂]=[0;0]
The coefficient matrix has det = W(x₀) ≠ 0 → only trivial solution
c₁=c₂=0 → f,g are LI ∎
Aᵀ=−A ⟹ e^{At} is orthogonal
Show (e^{At})ᵀ(e^{At})=I
(e^{At})ᵀ = e^{(At)ᵀ} = e^{Aᵀt} = e^{−At}
(e^{At})ᵀ·e^{At} = e^{−At}·e^{At} = e^{(−A+A)t} = e^0 = I
∴ e^{At} is orthogonal ∎

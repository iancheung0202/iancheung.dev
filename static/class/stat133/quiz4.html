1. Joins

All joins take two data frames and a by key. If the key columns have different names, use by = c("left_col" = "right_col").

Use these two sample tables for all examples below:

Table x — students

id name
1 Alice
2 Bob
3 Carol

Table y — scores

id score
1 88
2 95
4 73

Note: id = 3 (Carol) is only in x. id = 4 is only in y.

students <- data.frame(id = c(1, 2, 3), name = c("Alice", "Bob", "Carol"))
scores   <- data.frame(id = c(1, 2, 4), score = c(88, 95, 73))

1.1 Mutating Joins — Add Columns

These joins add columns from the right table to the left.

left_join() — keep all rows of x

left_join(students, scores, by = "id")
id name score
1 Alice 88
2 Bob 95
3 Carol NA

Carol has no match in scores → NA. id=4 from scores is dropped.

right_join() — keep all rows of y

right_join(students, scores, by = "id")
id name score
1 Alice 88
2 Bob 95
4 NA 73

id=4 has no match in students → NA. Carol is dropped.

⚠️ left_join(A, B) ≡ right_join(B, A) — same data, just different column ordering.

inner_join() — only matched rows

inner_join(students, scores, by = "id")
id name score
1 Alice 88
2 Bob 95

Only id=1 and id=2 exist in both tables. Carol (id=3) and id=4 are both dropped.

full_join() — all rows from both

full_join(students, scores, by = "id")
id name score
1 Alice 88
2 Bob 95
3 Carol NA
4 NA 73

Nothing is dropped. Unmatched values filled with NA.

1.2 Filtering Joins — Filter Rows Only

These joins do not add columns — they only keep or remove rows from x.

semi_join() — keep x rows that have a match in y

semi_join(students, scores, by = "id")
id name
1 Alice
2 Bob

Only the students columns are kept. Carol (id=3) is dropped since she has no score.

anti_join() — keep x rows with NO match in y

anti_join(students, scores, by = "id")
id name
3 Carol

Returns only Carol — the one student who does NOT appear in scores.

1.3 Different Key Names

When the join key has different column names in each table, use by = c("x_col" = "y_col"):

# "origin" in flights matches "faa" in airports
inner_join(flights, airports, by = c("origin" = "faa"))

# Chaining multiple joins
flights |>
  inner_join(airports, by = c("origin" = "faa")) |>
  inner_join(planes,   by = "tailnum")

2. Pivots

Reshaping data between wide and long format.

2.1 pivot_longer() — Wide → Long

Collapse multiple columns into two: a names column and a values column.

pivot_longer(df,
  cols      = <columns to pivot>,
  names_to  = "new_key_col",
  values_to = "new_val_col"
)

Before (wide):

country 2005 2006 2007
ARB 162M 168M 174M
CEB 91M 91M 91M 
df |>
  pivot_longer(
    cols      = c("2005", "2006", "2007"),
    names_to  = "year",
    values_to = "pop"
  )

After (long):

country year pop
ARB 2005 162M
ARB 2006 168M
ARB 2007 174M
CEB 2005 91M
CEB 2006 91M
CEB 2007 91M

Each year column becomes a row. 2 rows × 3 year-cols → 6 rows.

2.2 pivot_wider() — Long → Wide

Spread a key column’s values into separate columns.

pivot_wider(df,
  names_from  = <col whose values become new col names>,
  values_from = <col whose values fill the new cols>,
  values_fill = <replace NAs with this>   # optional
)

Before (long):

fish station seen
4842 Release 1
4842 I80_1 1
4843 Release 1 
fish_encounters |>
  pivot_wider(
    names_from  = station,
    values_from = seen,
    values_fill = 0
  )

After (wide):

fish Release I80_1 …
4842 1 1 …
4843 1 0 …

Each unique value of station becomes its own column. Missing combos filled with 0 (instead of NA).

3. Regular Expressions (Regex)

All patterns are used inside stringr functions as the pattern argument. Examples below use:

animals <- c("dog", "cat", "bird", "dolphin", "lion", "eagle", "kangaroo", "koala")
files <- c("sales1.csv", "orders.csv", "CA.csv", "sales-europe.csv")

3.1 Literal Characters

Match exactly what you type.

str_subset(animals, "dog")
# > "dog"

str_subset(animals, "ol")
# > "dolphin" "koala"

3.2 Wildcard .

. matches any single character.

str_subset(animals, "o.l")   # "o" + any char + "l"
# > "dolphin" ← "dol" = d-o-l, o.l matches o+any+l

str_subset(animals, "ea.")   # "ea" + any one char
# > "eagle" ← "eag" matches

3.3 Escape \\.

\\. matches a literal dot (not any character).

str_subset(files, "\\.")       # files containing a literal dot
# > "sales1.csv" "orders.csv" "CA.csv" "sales-europe.csv"

str_subset(files, "s\\.csv")   # "s" then literal dot then "csv"
# > "orders.csv"

3.4 Character Sets [...]

Match one character from the set.

# Any vowel
str_subset(animals, "[aeiou]")
# > "dog" "cat" "bird" "dolphin" "lion" "eagle" "kangaroo" "koala"  ← all have a vowel

# Two vowels in a row
str_subset(animals, "[aeiou]{2}")
# > "lion" "eagle" "kangaroo" "koala"

# Files with digits
str_subset(files, "[0-9]")
# > "sales1.csv"

# Files with uppercase letters before the dot
str_subset(files, "[A-Z]")
# > "CA.csv"

3.5 POSIX Classes

str_subset(files, "[[:digit:]]")   # ≡ [0-9]
# > "sales1.csv"

str_subset(files, "[[:upper:]]")   # ≡ [A-Z]
# > "CA.csv"

str_subset(files, "[[:punct:]]")   # any punctuation (. or -)
# > "sales1.csv" "orders.csv" "CA.csv" "sales-europe.csv"

3.6 Abbreviated Classes

str_subset(files, "\\d")    # ≡ [0-9]
# > "sales1.csv"

str_subset(files, "\\w-\\w")  # word char, dash, word char
# > "sales-europe.csv"

3.7 Anchors ^ and $

# Starts with "s"
str_subset(animals, "^s")
# > (none in this set)

str_subset(files, "^s")
# > "sales1.csv" "sales-europe.csv"

# Ends with "a"
str_subset(animals, "a$")
# > "koala"

# Exactly 3 letters
str_subset(animals, "^[a-z]{3}$")
# > "dog" "cat"

# Exactly 4 letters
str_subset(animals, "^[a-z]{4}$")
# > "bird" "lion"

# Remove extension only at the end
str_remove(files, "\\.csv$")
# > "sales1" "orders" "CA" "sales-europe"

3.8 Quantifiers

Pattern Meaning
a{m} exactly m of a
a{m,n} m to n of a
a* 0 or more
a+ 1 or more
a? 0 or 1 (optional) 
# o+ : one or more "o"
str_subset(animals, "o+")
# > "dog" "dolphin" "lion" "kangaroo" "koala"

# oo : exactly two "o"s together
str_subset(animals, "oo")
# > "kangaroo"

# one "o" but NOT two "o"s
str_subset(animals, "o")[!str_detect(str_subset(animals, "o"), "oo")]
# simpler:
animals[str_detect(animals, "o") & !str_detect(animals, "oo")]
# > "dog" "dolphin" "lion" "koala"

# Two or more consonants together
str_subset(animals, "[^aeiou]{2,}")
# > "bird" "dolphin" "eagle" "kangaroo"

4. stringr Functions

All functions are vectorized — they operate on every element of a character vector. Load with library(tidyverse) or library(stringr).

x <- c("apple", "banana", "cherry", "date", "grape")

str_count()

Count occurrences of a pattern in each string.

str_count(x, "a")
# > 1 3 0 1 1

str_sub()

Extract or replace a substring by position.

str_sub(x, 1, 3)          # first 3 characters
# > "app" "ban" "che" "dat" "gra"

str_sub(x, -3, -1)        # last 3 characters
# > "ple" "ana" "rry" "ate" "ape"

str_subset()

Return elements of the vector that match a pattern (like x[str_detect(x, pattern)]).

str_subset(x, "a")
# > "apple" "banana" "date" "grape"

str_detect()

Returns a logical vector — TRUE if the pattern is found.

str_detect(x, "^a")     # starts with "a"
# > TRUE FALSE FALSE FALSE FALSE

# Common use: filtering rows in dplyr
dat |> filter(str_detect(col, pattern))

# Or logical subsetting
animals[str_detect(animals, "o+")]

str_extract() and str_extract_all()

Extract the first match (or all matches) of a pattern.

str_extract(x, "[aeiou]+")        # first vowel run
# > "a" "a" "e" "a" "a"

str_extract_all("banana", "[aeiou]")  # all vowels
# > list(c("a", "a", "a"))

str_replace() and str_replace_all()

Replace the first match (or all matches) with a new string.

str_replace(x, "a", "A")       # replace first "a"
# > "Apple" "bAnana" "cherry" "dAte" "grApe"

str_replace_all(x, "a", "A")  # replace all "a"
# > "Apple" "bAnAnA" "cherry" "dAte" "grApe"

# Change file extension
str_replace(files, "csv$", "txt")

str_remove() and str_remove_all()

Remove the first match (or all matches) — shorthand for str_replace(x, pattern, "").

str_remove(x, "a")          # remove first "a"
# > "pple" "bnana" "cherry" "dte" "grpe"

str_remove_all(x, "a")      # remove all "a"
# > "pple" "bnn" "cherry" "dte" "grpe"

# Remove file extension
str_remove(files, "\\.csv$")
# > "sales1" "orders" "sales2" ...

str_split()

Split strings by a delimiter pattern. Returns a list.

str_split(c("a,b,c", "x,y"), ",")
# > list(c("a","b","c"), c("x","y"))

str_split("one two  three", "\\s+")  # split on whitespace
# > list(c("one","two","three"))

5. Quarto Dashboards

YAML Header

---
title: "My Dashboard"
format:
  dashboard:
    orientation: columns   # or "rows"
embed-resources: true
---

Layout

Dashboards use Markdown headings to define layout — no special syntax needed.

Heading Creates
## Column or ## Row A new column or row (depending on orientation)
### Card Title A card (panel) within that column/row
{width=60%} Set relative width of a column 
## Column {width=60%}

### Plot Title

[code chunk with ggplot]

## Column {width=40%}

### Summary

Some text or a table.

Value Boxes

A code chunk with #| component: valuebox renders as a colored summary box. Return a named list with icon, color, and value.

#| component: valuebox
list(
  icon  = "fuel-pump",
  color = "success",      # "primary", "secondary", "warning", "danger", etc.
  value = paste(max_hwy, "MPG")
)

Code Chunk Options for Dashboards

#| label: my-plot
#| title: "Chart Title"     # appears as card header
#| echo: false
#| message: false

Full Minimal Example

---
title: "MPG Dashboard"
format:
  dashboard:
    orientation: columns
---

```{r}
#| label: setup
#| message: false
library(tidyverse)
library(gt)
```

## Column {width=60%}

### Highway MPG by Class

```{r}
#| label: plot
ggplot(mpg, aes(x = class, y = hwy)) + geom_boxplot()
```

## Column {width=40%}

### Best MPG

```{r}
#| component: valuebox
list(icon = "speedometer", color = "success", value = max(mpg$hwy))
```

### Top Models

```{r}
mpg |> slice_max(hwy, n = 5) |> select(manufacturer, model, hwy) |> gt()
```

⚠️ Key Notes

  • format: dashboard (not format: html) — renders as a dashboard layout, not a regular doc.
  • Each ### card automatically gets a title from the heading text, or you can override it with #| title: in the chunk.
  • embed-resources: true bundles everything into a single .html file.
  • For interactive dashboards (e.g. Shiny widgets, leaflet maps), include server: shiny in the YAML.

6. Quick Reference

Joins Cheatsheet

left_join(x, y)   → all x rows          | right_join(x, y) → all y rows
inner_join(x, y)  → matched rows only   | full_join(x, y)  → all rows, NA fill
semi_join(x, y)   → x rows that match y (no new cols)
anti_join(x, y)   → x rows with NO match in y (no new cols)

Regex Quick Reference

.        any char          ^        start of string
\\.      literal dot       $        end of string
[abc]    a, b, or c        [^abc]   not a, b, c
[a-z]    a through z       [0-9]    digit
\\d      digit             \\w      word char
*        0 or more         +        1 or more
?        0 or 1            {m,n}    m to n times

stringr One-Liner Reference

str_count(x, pat)           # count matches per element
str_sub(x, start, end)      # substring by position
str_subset(x, pat)          # return matching elements
str_detect(x, pat)          # TRUE/FALSE — has match?
str_extract(x, pat)         # first match
str_extract_all(x, pat)     # all matches → list
str_replace(x, pat, rep)    # replace first match
str_replace_all(x, pat, rep)# replace all matches
str_remove(x, pat)          # remove first match
str_remove_all(x, pat)      # remove all matches
str_split(x, pat)           # split by pattern → list

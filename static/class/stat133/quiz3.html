1. Factors

What is a Factor?

A factor is R’s data type for categorical variables. It stores values as integer codes internally, but displays them as labels (called levels). Levels have an implicit order (alphabetical by default) unless you specify one.

Creating Factors

# Basic factor
sizes <- c("small", "large", "medium", "small", "large")
f <- factor(sizes)
f
# > [1] small  large  medium small  large
# > Levels: large medium small     ← alphabetical default

# Specify level order manually
f_ordered <- factor(sizes, levels = c("small", "medium", "large"))
f_ordered
# > Levels: small medium large

# Ordered (ordinal) factor
f_ord <- factor(sizes, levels = c("small", "medium", "large"), ordered = TRUE)
f_ord
# > Levels: small < medium < large

Key Functions

levels(f)          # returns character vector of levels
nlevels(f)         # number of levels
as.integer(f)      # underlying integer codes
as.character(f)    # convert back to character
table(f)           # frequency count of each level

Relabeling and Releveling

# Change level labels
levels(f) <- c("L", "M", "S")   # rename in same order

# Drop unused levels
f2 <- f[f != "L"]
f2 <- droplevels(f2)  # removes "L" from levels list

# Reorder levels (useful for ggplot bar ordering)
f_reorder <- factor(f, levels = c("S", "M", "L"))

⚠️ Nuances to Remember

  • Factors look like characters but are stored as integers — watch out with string operations.
  • typeof(factor(...)) returns "integer", but class() returns "factor".
  • Adding a value not in levels produces NA.
  • c(factor1, factor2) drops factor class — use forcats::fct_c() or factor(c(levels(...))) to combine.

2. Data Frames — Subsetting

Structure

df <- data.frame(
  name   = c("Alice", "Bob", "Carol"),
  score  = c(88, 95, 72),
  passed = c(TRUE, TRUE, FALSE)
)
df
# >    name score passed
# > 1 Alice    88   TRUE
# > 2   Bob    95   TRUE
# > 3 Carol    72  FALSE

Subsetting Syntax

# By index [row, col]
df[1, ]          # first row, all columns
df[, 2]          # all rows, second column → vector
df[1:2, c(1,3)]  # rows 1–2, cols 1 and 3

# By name
df[, "score"]         # column as vector
df["score"]           # column as data frame (1-col df)
df$score              # column as vector (same as df[,"score"])

# Logical subsetting
df[df$score >= 90, ]         # rows where score >= 90
df[df$passed == TRUE, "name"] # names of students who passed

# subset() — cleaner syntax
subset(df, score >= 85, select = c(name, score))
# >    name score
# > 1 Alice    88
# > 2   Bob    95

Useful Inspection Functions

nrow(df)    # number of rows
ncol(df)    # number of columns
dim(df)     # c(nrow, ncol)
head(df)    # first 6 rows
tail(df, 3) # last 3 rows
str(df)     # structure overview
names(df)   # column names

⚠️ Nuances

  • df[, "col"] returns a vector; df["col"] returns a 1-column data frame.
  • Tibbles (from tidyverse) always return a tibble when subset with [.

3. Pipe Operator |>

The native pipe |> (R 4.1+) passes the result of the left-hand side as the first argument of the right-hand side.

# These are equivalent:
filter(mpg, cyl == 4)
mpg |> filter(cyl == 4)

# Chain multiple operations
mpg |>
  filter(year == 2008) |>
  select(manufacturer, model, hwy) |>
  arrange(desc(hwy))

⚠️ Nuances

  • |> is the native pipe (base R ≥ 4.1). %>% is the magrittr pipe (tidyverse). They are mostly interchangeable.
  • |> does not support the . placeholder syntax that %>% does.
  • The pipe passes to the first argument — functions that don’t take data first need a lambda: \(x) fun(y, x).

4. Data Wrangling with dplyr

All dplyr functions take a data frame as the first argument and return a data frame.

library(tidyverse)
# Using mpg dataset for all examples below
dat <- mpg |> filter(year == 2008)

4.1 slice() — Subset Rows by Position

slice(df, rows)           # select rows by index
slice_head(df, n = 5)     # first 5 rows
slice_tail(df, n = 5)     # last 5 rows
slice_max(df, col, n = 3) # top 3 rows by column value
slice_min(df, col, n = 3) # bottom 3 rows by column value
slice_sample(df, n = 10)  # random sample of 10 rows

dat |> slice(1:5) # rows 1 to 5
dat |> slice(seq(10, 50, by = 5))   # rows 10, 15, 20, ..., 50
dat |> slice_max(order_by = hwy, n = 3)  # 3 cars with best highway mpg

⚠️ Rule: slice() uses row positions (integers), not conditions. Use filter() for conditions.

4.2 select() — Subset Columns

select(df, col1, col2)        # keep named columns
select(df, -col1)             # drop col1
select(df, col1:col3)         # range of columns
select(df, starts_with("m"))  # columns starting with "m"
select(df, ends_with("y"))    # columns ending with "y"
select(df, contains("pg"))    # columns containing "pg"

dat |> select(manufacturer, model, hwy) # keep the three columns
dat |> select(-year, -trans)   # drop year and trans columns

4.3 filter() — Subset Rows by Condition

filter(df, condition)
filter(df, cond1, cond2)   # AND — both must be TRUE
filter(df, cond1 | cond2)  # OR  — at least one TRUE

dat |> filter(displ == 5.7)
dat |> filter(displ >= 5.5, displ <= 5.7)   # between (AND)
dat |> filter(displ < 2 | displ > 6.5)      # outside range (OR)
dat |> filter(manufacturer %in% c("honda", "toyota"))  # multiple values
dat |> filter(!is.na(cty))   # drop NAs

⚠️ Nuances:

  • Use == not = for equality tests.
  • Use %in% to test membership in a vector (cleaner than repeated |).
  • Comma between conditions ≡ & (AND).

4.4 count() — Frequency Counts

count(df, col)                      # count rows per unique value
count(df, col, name = "my_count")   # rename count column
count(df, col1, col2)               # count combinations

dat |> count(class)
# >   class          n
# > 1 2seater        5
# > 2 compact       25
# > ...
dat |> count(manufacturer, class)   # cross-tabulation
dat |> count(cyl, name = "num_cars")

⚠️ Rule: count(x) is shorthand for group_by(x) |> summarize(n = n()).

4.5 mutate() — Add or Modify Columns

mutate(df, new_col = expression)
mutate(df, new_col = expression, another_col = expression2)  # multiple at once

dat |> mutate(cmpg = cty * 0.55 + hwy * 0.45) # Adds a column `cmpg` for combined mpg

dat |> mutate(
  cmpg      = cty * 0.55 + hwy * 0.45,
  hwy_class = if_else(hwy >= 30, "efficient", "standard")
)

⚠️ Nuances:

  • mutate() returns the whole data frame with the new column added.
  • You can reference a newly created column in the same mutate() call.
  • Use transmute() if you want to keep only the new columns.

4.6 arrange() — Sort Rows

arrange(df, col)           # ascending (default)
arrange(df, desc(col))     # descending
arrange(df, col1, col2)    # sort by col1 then col2

dat |> arrange(hwy)          # lowest hwy first
dat |> arrange(desc(hwy))    # highest hwy first
dat |> arrange(manufacturer, desc(hwy))  # alphabetical by make, then best hwy

4.7 summarize() — Collapse to Summary Statistics

summarize(df, stat_name = agg_function(col))

dat |> summarize(
  mean_hwy = mean(hwy, na.rm = TRUE),
  max_cty  = max(cty,  na.rm = TRUE),
  n        = n()          # n() counts rows
)
# >   mean_hwy max_cty     n
# > 1     23.5      35   107

Common aggregation functions: mean(), median(), sum(), min(), max(), sd(), n(), n_distinct().

⚠️ Rule: summarize() collapses many rows → one row (or one row per group when used with group_by()).

4.8 group_by() — Grouped Operations

group_by(df, col)                  # group by one variable
group_by(df, col1, col2)           # group by multiple variables
ungroup(df)                        # remove grouping

group_by() by itself doesn’t change the visible data — it adds grouping metadata that affects subsequent verbs.

dat |>
  group_by(manufacturer) |>
  summarize(mean_cty = mean(cty, na.rm = TRUE))
# >   manufacturer mean_cty
# > 1 audi             17.6
# > 2 chevrolet        15  
# > ...

dat |>
  group_by(class) |>
  summarize(max_cty = max(cty)) |>
  arrange(class)

group_by() + mutate() → adds group-specific column (keeps all rows):

dat |>
  group_by(manufacturer) |>
  mutate(rank_hwy = rank(desc(hwy)))  # ranks within each manufacturer group

⚠️ Nuances:

  • After summarize(), the last grouping variable is dropped (one level of grouping removed).
  • Use .groups = "drop" in summarize() to drop all grouping: summarize(..., .groups = "drop").

5. Importing Tables

Base R — read.table() and friends

# General function — you specify delimiter
read.table("file.txt", header = TRUE, sep = ",")

# Convenience wrappers:
read.csv("file.csv")       # comma-separated, header = TRUE default
read.csv2("file.csv")      # semicolon-separated (European format)
read.delim("file.tsv")     # tab-separated
read.delim2("file.tsv")    # tab-separated, decimal = ","
Function Separator Decimal
read.csv() , .
read.csv2() ; ,
read.delim() \t (tab) .
read.delim2() \t (tab) ,

Key arguments:

read.table("file.txt",
  header    = TRUE,   # first row is column names
  sep       = ",",    # delimiter character
  skip      = 2,      # skip first 2 lines
  nrows     = 100,    # read only 100 rows
  na.strings = "NA",  # what string represents NA
  stringsAsFactors = FALSE  # don't auto-convert strings to factors
)

Returns: a data.frame.

readr — read_csv() and friends

library(readr)  # or library(tidyverse)

read_csv("file.csv")        # comma-separated
read_csv2("file.csv")       # semicolon-separated
read_tsv("file.tsv")        # tab-separated
read_delim("file.txt", delim = "|")  # custom delimiter
read_table("file.txt")      # whitespace-separated

Returns: a tibble (enhanced data frame).

Key differences from base R:

Feature read.csv() (base) read_csv() (readr)
Output type data.frame tibble
String handling converts to factor (old default) keeps as character
Speed slower faster
Column type messages none prints column spec
NA handling na.strings = na =

Common arguments:

read_csv("file.csv",
  col_names = TRUE,       # first row is header
  col_types = "cdi",      # c=char, d=double, i=integer per column
  skip = 1,               # skip 1 line
  n_max = 500,            # read max 500 rows
  na = c("", "NA", "N/A") # strings treated as NA
)

⚠️ Nuances:

  • read_csv (underscore, readr) ≠ read.csv (dot, base R) — different output types and defaults.
  • read_table() (readr) ≠ read.table() (base R) — read_table is for single-whitespace-separated files.
  • readr prints a column specification message — this is informational, not an error.

6. Grammar of Graphics

The Grammar of Graphics is a framework for describing any plot as a combination of layered components:

Component Role Example
Data The data frame to visualize mpg
Aesthetics (aes) Map variables to visual properties x = displ, y = hwy, color = class
Geometries (geom_*) The shape/type of plot geom_point(), geom_bar()
Facets Split into sub-plots by a variable facet_wrap(~ class)
Statistics (stat_*) Statistical transformations stat_smooth()
Coordinates Coordinate system coord_flip()
Themes Non-data visual styling theme_minimal()

Mappings vs Settings — the most tested concept:

  • Mapping: connects a visual property to a variable → goes inside aes().
  • Setting: fixes a visual property to a constant → goes outside aes(), directly in geom_*().
# MAPPING — color varies by the `class` variable
ggplot(mpg, aes(x = displ, y = hwy, color = class)) + geom_point()

# SETTING — all points are fixed blue
ggplot(mpg, aes(x = displ, y = hwy)) + geom_point(color = "blue")

# WRONG — putting a constant inside aes() doesn't make it blue
ggplot(mpg, aes(x = displ, y = hwy, color = "blue")) + geom_point()
# ggplot treats "blue" as a categorical variable, not the color blue

7. Graphics with ggplot2

Basic Template

ggplot(data = <DATA>, mapping = aes(<MAPPINGS>)) +
  <GEOM_FUNCTION>()

7.1 Mappings (aes())

Aesthetic properties you can map:

Aesthetic Description
x, y Position on axes
color Color of points/lines/borders
fill Fill color (bars, areas)
size Size of points/lines
shape Shape of points
alpha Transparency (0–1)
linetype Type of line (solid, dashed, …)
label Text labels

Global vs Local mappings:

# Global — all geoms inherit
ggplot(mpg, aes(x = displ, y = hwy, color = class)) +
  geom_point() +
  geom_smooth()   # also colored by class

# Local — only affects this geom
ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point(aes(color = class)) +  # color only on points
  geom_smooth()                      # smooth has no color

7.2 Geometries (geom_*)

Univariate (one variable):

geom_histogram()    # continuous — bars showing frequency distribution
geom_density()      # continuous — smooth density curve
geom_bar()          # categorical — counts per category (no y needed)
geom_boxplot()      # distribution summary
geom_violin()       # like boxplot + density shape

Bivariate (two variables):

geom_point()        # scatter plot
geom_line()         # line connecting points (time series)
geom_smooth()       # trend/regression line with CI band
geom_col()          # bar chart with explicit y values (vs geom_bar)
geom_text()         # text labels at each point
geom_label()        # text labels with background box

Reference lines:

geom_hline(yintercept = 0)              # horizontal line
geom_vline(xintercept = 4)              # vertical line
geom_abline(slope = 1, intercept = 0)  # diagonal line

Example — multiple geoms:

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point(aes(color = class)) +
  geom_smooth(method = "lm") +
  geom_hline(yintercept = mean(mpg$hwy), color = "red", linetype = "dashed")

7.3 Settings vs Mappings (Key Examples)

# Size as SETTING — all points size 3
geom_point(size = 3)

# Size as MAPPING — size varies with cyl
geom_point(aes(size = cyl))

# nudge_y is ALWAYS a setting (outside aes)
geom_text(aes(label = model), nudge_y = 0.5)

7.4 Facets

facet_wrap() — wraps panels for one variable, left to right then top to bottom:

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_wrap(~ class)           # one panel per class

facet_wrap(~ class, nrow = 2)   # force 2 rows
facet_wrap(~ class, ncol = 3)   # force 3 columns

facet_grid() — creates a grid of panels for two variables:

facet_grid(rows ~ cols)

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_grid(drv ~ cyl)       # rows = drv, cols = cyl

facet_grid(. ~ year)          # columns only (. = no row variable)
facet_grid(year ~ .)          # rows only
facet_grid(cols = vars(year)) # equivalent to above with vars()

⚠️ facet_wrap vs facet_grid:

  • facet_wrap: one variable, wraps panels into a grid automatically.
  • facet_grid: two variables, explicit rows and columns.

7.5 Labels and Themes

ggplot(iris, aes(x = Sepal.Length, y = Petal.Length, color = Species)) +
  geom_point() +
  labs(
    title    = "Sepal vs Petal Length",
    subtitle = "By species",
    x        = "Sepal Length (cm)",
    y        = "Petal Length (cm)",
    color    = "Species"          # rename legend title
  ) +
  theme_minimal()    # apply a clean theme

Built-in themes: theme_gray() (default), theme_minimal(), theme_classic(), theme_bw(), theme_light(), theme_dark(), theme_void().

Annotation:

annotate("text", x = 5, y = 3, label = "Interesting cluster",
         color = "darkred", fontface = "italic")

8. Common Mistakes & Rules

❌ Wrong ✅ Right Why
color = "blue" inside aes() color = "blue" outside aes() Setting, not a variable
filter(df, x = 5) filter(df, x == 5) Need == for comparison
read_csv vs read.csv mixed up Know both; _ is readr (tibble), . is base (data.frame) Different outputs
facet_wrap(year ~ class) facet_wrap(~ class) or facet_grid(year ~ class) facet_wrap takes only one variable
ggplot(...) \n geom_point() (newline, no +) ggplot(...) +\n geom_point() + must be at end of line, not beginning
Plotting constant in aes() Move it outside aes() to the geom Constants are settings

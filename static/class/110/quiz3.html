Quiz Review: Adjoints & Positive Semidefinite Square Roots

Two main question types are flagged:

  1. "Something like Example 1 or 2 but not exactly" → computing an adjoint (matrix-style or Riesz-representation-style)
  2. "Give you a matrix and find the square root" → finding T\sqrt{T}T​, likely including the rank-one perturbation exercise

0. Quick-Reference Cheat Sheet

Definition: T∗T^*T∗ satisfies ⟨Tv,w⟩=⟨v,T∗w⟩\langle Tv, w \rangle = \langle v, T^*w \rangle⟨Tv,w⟩=⟨v,T∗w⟩ for all v,wv, wv,w.

Algebraic properties:

(S+T)∗=S∗+T∗,(λT)∗=λˉT∗,(ST)∗=T∗S∗,(T−1)∗=(T∗)−1,(T∗)∗=T(S+T)^* = S^* + T^*, \qquad (\lambda T)^* = \bar\lambda T^*, \qquad (ST)^* = T^*S^*, \qquad (T^{-1})^* = (T^*)^{-1}, \qquad (T^*)^* = T (S+T)∗=S∗+T∗,(λT)∗=λˉT∗,(ST)∗=T∗S∗,(T−1)∗=(T∗)−1,(T∗)∗=T

Matrix fact (standard inner product ⟨x,y⟩=y∗x\langle x,y\rangle = y^*x⟨x,y⟩=y∗x): T∗=A∗T^* = A^*T∗=A∗ (conjugate transpose).

Self-adjoint: T∗=T  ⟺  ⟨Tv,v⟩∈RT^* = T \iff \langle Tv,v\rangle \in \mathbb{R}T∗=T⟺⟨Tv,v⟩∈R for all vvv.

Positive semidefinite (PSD) — all equivalent:

  1. T∗=TT^*=TT∗=T and ⟨Tv,v⟩≥0\langle Tv,v\rangle \ge 0⟨Tv,v⟩≥0 for all vvv
  2. T=T∗T=T^*T=T∗ and all eigenvalues ≥0\ge 0≥0
  3. Diagonal (entries ≥0\ge 0≥0) in some orthonormal basis
  4. TTT has a unique PSD square root
  5. TTT has some self-adjoint square root
  6. T=R∗RT = R^*RT=R∗R for some RRR

Square root: S2=TS^2 = TS2=T. If TTT is PSD, the PSD square root is unique.

1. Question Type A: Matrix Adjoints

Generic Template

Given an inner product on Cn\mathbb{C}^nCn (standard ⟨x,y⟩=y∗x\langle x,y\rangle = y^*x⟨x,y⟩=y∗x, or weighted ⟨x,y⟩=y∗Wx\langle x,y\rangle = y^*Wx⟨x,y⟩=y∗Wx) and a matrix AAA, find T∗=BT^*=BT∗=B:

  1. Write LHS=⟨Ax,y⟩\text{LHS} = \langle Ax,y\rangleLHS=⟨Ax,y⟩ using the given inner product.
  2. Write RHS=⟨x,By⟩\text{RHS} = \langle x,By\rangleRHS=⟨x,By⟩ using the given inner product.
  3. Expand both sides fully in terms of matrix products.
  4. Set LHS=RHS\text{LHS}=\text{RHS}LHS=RHS for all x,yx,yx,y and cancel to isolate BBB (or B∗B^*B∗).
  5. Solve for BBB; state T∗=BT^* = BT∗=B.
  6. (Optional) Sanity check with W=IW=IW=I — should reduce to the standard case T∗=A∗T^*=A^*T∗=A∗.

Example A1 — standard inner product

A∈Cn×nA \in \mathbb{C}^{n\times n}A∈Cn×n, ⟨x,y⟩=y∗x\langle x,y\rangle = y^*x⟨x,y⟩=y∗x. Find BBB with ⟨Ax,y⟩=⟨x,By⟩\langle Ax,y\rangle = \langle x,By\rangle⟨Ax,y⟩=⟨x,By⟩.

LHS=y∗(Ax)=y∗Ax,RHS=(By)∗x=y∗B∗x\text{LHS} = y^*(Ax) = y^*Ax, \qquad \text{RHS} = (By)^*x = y^*B^*x LHS=y∗(Ax)=y∗Ax,RHS=(By)∗x=y∗B∗x

Matching: A=B∗  ⟹  B=A∗A = B^* \implies B = A^*A=B∗⟹B=A∗.

T∗=A∗T^* = A^*T∗=A∗ (conjugate transpose). E.g. A=(12i34)  ⟹  A∗=(13−2i4)A=\begin{pmatrix}1 & 2i\\ 3 & 4\end{pmatrix} \implies A^* = \begin{pmatrix}1 & 3\\ -2i & 4\end{pmatrix}A=(13​2i4​)⟹A∗=(1−2i​34​).

Example A2 — weighted inner product

⟨x,y⟩=y∗Wx\langle x,y\rangle = y^*Wx⟨x,y⟩=y∗Wx, WWW Hermitian positive-definite.

LHS=y∗WAx,RHS=(By)∗Wx=y∗B∗Wx\text{LHS} = y^*WAx, \qquad \text{RHS} = (By)^*Wx = y^*B^*Wx LHS=y∗WAx,RHS=(By)∗Wx=y∗B∗Wx

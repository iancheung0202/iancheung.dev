public class Sort {
    /** Finds index of the smallest String in x, starting at index start */
    public static int findSmallest(String[] x, int start) {
        int smallest = start;
        for (int i = start; i < x.length; i += 1) {
            int cmp = x[i].compareTo(x[smallest]); // Compare strings using compareTo
            if (cmp < 0) {
                smallest = i;
            }
        }
        return smallest;
    }

    /** Swaps elements at indices a and b in array x */
    public static void swap(String[] x, int a, int b) {
        String temp = x[a];
        x[a] = x[b];
        x[b] = temp;
    }
    
    public static void sort(String[] x) {
        sort(x, 0); // Call the recursive helper starting at index 0
    }

    /** Sorts the array starting at index start */
    private static void sort(String[] x, int start) {
        if (start == x.length) { // Base case
            return;
        }
        int smallest = findSmallest(x, start); // Find smallest in remaining part
        swap(x, start, smallest);              // Move it to current front
        sort(x, start + 1);                    // Recurse on the rest
    }
}

        public IntNode next;

            item = i;
            next = n;
        }

    /* The first item (if it exists) is at sentinel.next. */
    private IntNode sentinel;
    private int size;

    public SLList() {

        size = 0;
    }

    /** Creates a non-empty SLList. */
    public SLList(int x) {
        sentinel = new IntNode(63, null); // 63 is any placeholder value
        sentinel.next = new IntNode(x, null);
        size = 1;
    }

    /** Adds x to the front of the list. */
    public void addFirst(int x) {
        sentinel.next = new IntNode(x, sentinel.next);

        return sentinel.next.item;
    }

        }
        p.next = new IntNode(x, null);
    }

        return size;
    }

            last.prev = sentinel; // D.prev = sentinel

            oldBack.prev = last; // A.prev from sentinel to D
            sentinel.next = last; // sentinel.next from A to D
        }
    }

import java.util.List;

public interface Deque61B<T> {
    void addFirst(T x);
    void addLast(T x);
    List<T> toList();
    boolean isEmpty();
    int size();
    T removeFirst();
    T removeLast();
    T get(int index);
    T getRecursive(int index);

    /**
     * Default method: removes x items from each end.
     * If size <= 2*x, empties the deque entirely.
     * Demonstrates how default methods provide shared logic
     * without requiring each implementing class to re-write it.
     */
    default void clipEnds(int x) {
        if (x <= 0) { return; }
        if (size() <= 2 * x) {
            while (!isEmpty()) { removeFirst(); }
            return;
        }
        for (int i = 0; i < x; i++) {
            removeFirst();
            removeLast();
        }
    }

    /** Fall 2025 Midterm 1 **/
    default boolean rotateToFront(T x) {
        int rotations = 0;
        while (rotations < size()) {
            if (getFirst().equals(x)) {
                return true;
            }
            addLast(removeFirst());
            rotations += 1;
        }
        return false;
    }

    default boolean rotateToFront(T x) { // Alternate Solution 
        for (int i = 0; i < size(); i++) {
            if (get(i).equals(x)) {
                for (int j = 0; j < i; j++) {
                    addLast(removeFirst());
                }
                return true;
            }
        }
        return false;
    }

    default boolean rotateToFront(T x) { // Alternate Solution 2
        int rotations = 0;
        while (!get(rotations).equals(x) && rotations < size()) {
            addLast(removeFirst());
            rotations++;
        }
        return rotations < size();
    }
}

4. Memory Box Model & References

Java handles memory through "boxes" of bits.

  • Primitive Types: There are 8 (byte, short, int, long, float, double, boolean, char). Declaring a primitive sets aside a box of a specific size (e.g., 32 bits for an int).
  • Reference Types: Everything else (Classes, Arrays) is a reference type. A reference variable box stores a 64-bit address (pointer) to the object in memory, not the object itself.
  • The Golden Rule of Equals (GRoE): y = x copies the bits from x into y. For reference types, this means copying the address, so both variables point to the same object.

5. Parameter Passing

Java uses pass-by-value, which follows the Golden Rule of Equals: when you pass a variable to a method, Java copies the bits into the method's local parameter.

  • If you pass a reference, you copy the address. Changes to the object the address points to will be visible outside the method.
  • If you pass a primitive, you copy the actual value. Changes to the local parameter do not affect the original variable.

Selection Sort Implementation

Selection Sort is built using helper methods: findSmallest (to locate the index of the minimum element) and swap (to move it).

Helper Methods

java 
public class Sort {
    /** Finds index of the smallest String in x, starting at index start */
    public static int findSmallest(String[] x, int start) {
        int smallest = start;
        for (int i = start; i < x.length; i += 1) {
            int cmp = x[i].compareTo(x[smallest]); // Compare strings using compareTo
            if (cmp < 0) {
                smallest = i;
            }
        }
        return smallest;
    }

    /** Swaps elements at indices a and b in array x */
    public static void swap(String[] x, int a, int b) {
        String temp = x[a];
        x[a] = x[b];
        x[b] = temp;
    }
}

Recursive Sort with Helper

Because Java does not allow sub-indexing into arrays (e.g., x[1:]), a recursive helper method is used to track the start index.

java 
public class Sort {
    public static void sort(String[] x) {
        sort(x, 0); // Call the recursive helper starting at index 0
    }

    /** Sorts the array starting at index start */
    private static void sort(String[] x, int start) {
        if (start == x.length) { // Base case
            return;
        }
        int smallest = findSmallest(x, start); // Find smallest in remaining part
        swap(x, start, smallest);              // Move it to current front
        sort(x, start + 1);                    // Recurse on the rest
    }
}

Lecture 6 — SLLists

1. Key Improvements: From IntList to SLList

While IntLists (naked linked lists) are functional, they are difficult for users because they require deep knowledge of references and recursion. The SLList (Singly Linked List) acts as a "middle man" to hide these complexities.

Feature IntList (Naked List) SLList (Class-based)
Complexity User deals directly with links and recursion. User calls simple methods like addFirst.
Empty List Difficult to represent; usually null. Easily represented by a sentinel node.
Size Slow; requires traversing the entire list. Fast; size is "cached" in a variable.

2. Syntax & Important Keywords

  • private (Access Control): Used to hide implementation details. It prevents users from directly manipulating internal pointers, which could break the list structure (e.g., creating infinite loops).
  • static Nested Class: When a class like IntNode is only useful to the SLList, it is defined inside SLList. If the nested class never uses the outer class's instance variables, it should be declared static to save memory.
  • sentinel: A special "placeholder" node that is always present, even in an empty list. This eliminates the need for "special case" code (like if (first == null)) when adding items.
  • Caching: The practice of storing a value (like size) instead of recalculating it every time, making retrieval significantly faster.

3. Example Code: The Complete SLList

    /**
     * Nested Class: static because it never uses
     * any of SLList's instance variables.
     */
    private static class IntNode {
        public int item;
        public IntNode next;

        public IntNode(int i, IntNode n) {
            item = i;
            next = n;
        }
    }

    /* The first item (if it exists) is at sentinel.next. */
    private IntNode sentinel;
    private int size;

    /** Creates an empty SLList. */
    public SLList() {
        // Sentinel holds a placeholder value (e.g., 63)
        sentinel = new IntNode(63, null);
        size = 0;
    }

    /** Creates a non-empty SLList. */

        sentinel = new IntNode(63, null); // 63 is any placeholder value
        sentinel.next = new IntNode(x, null);
        size = 1;
    }

    /** Adds x to the front of the list. */
    public void addFirst(int x) {
        sentinel.next = new IntNode(x, sentinel.next);
        size += 1;
    }

    /** Returns the first item in the list. */
    public int getFirst() {
        return sentinel.next.item;
    }

    /** Adds x to the end of the list. */
    public void addLast(int x) {
        size += 1;
        IntNode p = sentinel;
        while (p.next != null) {
            p = p.next;
        }
        p.next = new IntNode(x, null);
    }

    /** Returns the size of the list (using caching). */
    public int size() {
        return size;
    }
}

1. Doubly Linked Lists (DLLists)

Singly linked lists are slow at operations involving the back of the list (like removeLast) because they must traverse the entire list to find the second-to-last node. DLLists solve this by adding backwards links (prev) to every node.

  • Circular Sentinel: A more advanced topology (required for Project 1) where a single sentinel node's prev points to the last item and its next points to the first item.

    */
    public void rotateRight(int k) {
        for (int i = 0; i < k; i++) {
            Node last = sentinel.prev; // D
            Node oldBack = sentinel.next; // A
            Node newFront = last.prev; // C

            // ---- detach last from back ----
            newFront.next = sentinel; // C.next from D to sentinel
            sentinel.prev = newFront; // sentinel.prev from D to C

            // ---- move last to front ----
            last.next = oldBack; // D.next = A
            last.prev = sentinel; // D.prev = sentinel

            oldBack.prev = last; // A.prev from sentinel to D
            sentinel.next = last; // sentinel.next from A to D
        }
    }

}

Key Points:

  • The sentinel node's next always points to the front, and prev always points to the back — this eliminates all null-checks.
  • addFirst / addLast both require updating four pointers: the new node's two pointers, plus the sentinel's and neighbor's pointer pointing to the new node.
  • count(T x) demonstrates iterating over the deque using get(i) and .equals() for comparison.

3. Array-based Lists (ALists)

While linked lists are fast for adding/removing items at the ends, they are slow at get(int i) because they must scan through the nodes. ALists use an underlying array to provide random access, making retrieval fast regardless of size.

  • Invariants:
    • The next item to be inserted is always at index size.
    • The size variable always tracks the number of items currently in the list.
    • The last item is always at index size - 1.

Example Code (Basic AList):

java 
public class AList {
    private int[] items;
    private int size;

    public AList() {
        items = new int[100]; // Fixed starting size
        size = 0;
    }

    public void addLast(int x) {
        items[size] = x; // Invariant: next item goes at index 'size'
        size += 1;
    }

    public int getLast() {
        return items[size - 1]; // Invariant: last item is at 'size - 1'
    }

    public int get(int i) {
        return items[i]; // Fast random access
    }

    public int removeLast() {
        int x = getLast();
        size -= 1; // "Deleting" is often just decrementing the size
        return x;
    }
}

Important Keywords & Concepts

  • .prev: The pointer in a DLList that allows moving backwards through the list.
  • Sentinel Node: A placeholder node used to avoid "special case" code for empty lists.
  • Random Access: The ability to access any element in an array in constant time.
  • Caching: Storing a value (like size) so it doesn't have to be recomputed.
  • Invariant: A condition that is guaranteed to be true during code execution (e.g., "the first item is always at sentinel.next").

Lecture 8 — Resizing ALists

1. Geometric Resizing (Dynamic Arrays)

A basic AList with a fixed-size array (e.g., 100) will eventually run out of space. To fix this, we implement Resizing.

  • The Concept: When the array is full, create a new, larger array and copy all existing elements into it.
  • The Trap (Arithmetic Resizing): Adding a fixed number of slots (e.g., size + 1) is extremely slow (O(N²) for N additions) because copying happens too often.
  • The Solution (Geometric Resizing): Multiply the capacity (usually by 2). This ensures that the "amortized" time for addLast is O(1)—meaning it is very fast on average.

Example Code (Resizing):

java 
public void addLast(Item x) {
    if (size == items.length) {
        resize(items.length * 2); // Multiply capacity by 2
    }
    items[size] = x;
    size = size + 1;
}

private void resize(int capacity) {
    Item[] a = (Item[]) new Object[capacity]; // Create larger array
    System.arraycopy(items, 0, a, 0, size);   // Copy items to new array
    items = a;                                // Point to new array
}

2. Memory Efficiency & Downsizing

While geometric resizing handles growth, it doesn't handle shrinking. If we add 1 million items and then delete 990,000, we are wasting a massive amount of memory.

  • Usage Ratio (R): Defined as size / items.length.
  • Downsizing: In Java, a good rule of thumb is to halve the array size when the usage ratio falls below 25% (R < 0.25).
  • Loitering: When removing an item from an array of references (Generics), you should null out the reference (e.g., items[size-1] = null). This allows the Garbage Collector to reclaim that memory.

3. Generics in Arrays

To allow AList to store any type (like String or Dog), we use Generics. However, Java does not allow the direct creation of Generic arrays.

  • Syntax Hack: You must create an array of Object and cast it to the generic type.
  • Keywords: <Item> (formal type parameter).

Example Code (Generic AList):

4. Circular Arrays (The Deque Approach)

For a Deque (Double Ended Queue), we need fast addFirst and removeFirst. In a standard array, adding to the front requires shifting every element, which is O(N).

  • The Circular Strategy: Use nextFirst and nextLast pointers.
  • The Logic: If nextFirst is at index 0, adding an item moves nextFirst to the end of the array (index length - 1).
  • Syntax (Modulo): Use the modulo operator % to wrap indices around, or manual checks if the index goes out of bounds.

Full Implementation — ArrayDeque61B:

java 
import java.util.ArrayList;
import java.util.List;
import java.util.Iterator;

public class ArrayDeque61B<T> implements Deque61B<T> {
    private T[] items;
    private int size;
    private int nextFirst; // index where the next addFirst item will go
    private int nextLast;  // index where the next addLast item will go

    public ArrayDeque61B() {
        items = (T[]) new Object[8];
        size = 0;
        nextFirst = 4;
        nextLast = 5;
    }

    /** Resizes the underlying array to the given capacity. */
    private void resize(int capacity) {
        T[] newItems = (T[]) new Object[capacity];
        for (int i = 0; i < size; i++) {
            newItems[i] = get(i); // copy items in logical order
        }
        items = newItems;
        nextFirst = capacity - 1;
        nextLast = size;
    }

    @Override
    public void addFirst(T x) {
        if (size == items.length) { resize(items.length * 2); }
        items[nextFirst] = x;
        nextFirst = (nextFirst - 1 + items.length) % items.length;
        size += 1;
    }

    @Override
    public void addLast(T x) {
        if (size == items.length) { resize(items.length * 2); }
        items[nextLast] = x;
        nextLast = (nextLast + 1) % items.length;
        size += 1;
    }

    @Override
    public T removeFirst() {
        if (isEmpty()) { return null; }
        if (items.length >= 16 && size < items.length / 4) { resize(items.length / 2); }
        int index = (nextFirst + 1) % items.length;
        T item = items[index];
        items[index] = null; // avoid loitering
        nextFirst = index;
        size -= 1;
        return item;
    }

    @Override
    public T removeLast() {
        if (isEmpty()) { return null; }
        if (items.length >= 16 && size < items.length / 4) { resize(items.length / 2); }
        int index = (nextLast - 1 + items.length) % items.length;
        T item = items[index];
        items[index] = null; // avoid loitering
        nextLast = index;
        size -= 1;
        return item;
    }

    @Override
    public T get(int index) {
        if (index < 0 || index >= size) { return null; }
        return items[(nextFirst + 1 + index) % items.length];
    }

    @Override
    public T getRecursive(int index) {
        throw new UnsupportedOperationException("No need to implement getRecursive for ArrayDeque61B.");
    }

    @Override
    public int size() { return size; }

    @Override
    public boolean isEmpty() { return size == 0; }

    @Override
    public List<T> toList() {
        List<T> returnList = new ArrayList<>();
        for (int i = 0; i < size; i++) { returnList.add(get(i)); }
        return returnList;
    }

    /** Iterator enables for-each loops. */
    @Override
    public Iterator<T> iterator() {
        return new ArrayDequeIterator();
    }

    private class ArrayDequeIterator implements Iterator<T> {
        private int wizPos = 0;

        @Override
        public boolean hasNext() { return wizPos < size; }

        @Override
        public T next() {
            T returnItem = get(wizPos);
            wizPos += 1;
            return returnItem;
        }
    }

    /** Check equality: checks same size and same elements at each index. */
    @Override
    public boolean equals(Object o) {
        if (o instanceof Deque61B<?> otherDeque) {
            if (this.size() != otherDeque.size()) { return false; }
            for (int i = 0; i < size; i++) {
                if (!this.get(i).equals(otherDeque.get(i))) { return false; }
            }
            return true;
        }
        return false;
    }

    @Override
    public String toString() {
        String string = "[";
        for (int i = 0; i < size; i++) {
            string += get(i).toString();
            if (i < size - 1) { string += ", "; }
        }
        return string + "]";
    }

    /** PRACTICE PROBLEMS FROM CHATGPT */

    public ArrayDeque61B<T> everyOther() {
        ArrayDeque61B<T> result = new ArrayDeque61B<>();
        for (int i = 0; i < size; i += 2) {
            result.addLast(get(i));
        }
        return result;
    }

    public void removeEveryOther() {
        if (size <= 1) return;

        int originalSize = size;
        int removeCount = 0;

        for (int i = 1; i < originalSize; i += 2) {
            removeAtIndex(i - removeCount);
            removeCount++;
        }
    }

    public void insertAtIndex(int index, T item) {
        if (index < 0 || index > size) return;
        if (size == items.length) { resize(items.length * 2); }
        int insertPos = (nextFirst + 1 + index) % items.length;

        // shift elements right
        for (int i = size; i > index; i--) {
            int from = (nextFirst + 1 + i - 1) % items.length;
            int to   = (nextFirst + 1 + i) % items.length;
            items[to] = items[from];
        }

        items[insertPos] = item;
        nextLast = (nextLast + 1) % items.length;
        size++;
    }

    public T removeAtIndex(int index) {
        if (index < 0 || index >= size) return null;

        int removePos = (nextFirst + 1 + index) % items.length;
        T removedItem = items[removePos];

        // shift elements left
        for (int i = index; i < size - 1; i++) {
            int from = (nextFirst + 1 + i + 1) % items.length;
            int to   = (nextFirst + 1 + i) % items.length;
            items[to] = items[from];
        }

        int lastPos = (nextFirst + size) % items.length;
        items[lastPos] = null;

        nextLast = lastPos;
        size--;

        if (items.length >= 16 && size < items.length / 4) { resize(items.length / 2); }
        return removedItem;
    }

    public ArrayDeque61B<T> reversed() {
        ArrayDeque61B<T> result = new ArrayDeque61B<>();
        for (int i = size - 1; i >= 0; i--) {
            result.addLast(get(i));
        }
        return result;
    }

    public void rotateRight(int k) {
        if (size <= 1) return;
        k = k % size;

        for (int i = 0; i < k; i++) {
            int lastIndex = (nextLast - 1 + items.length) % items.length;
            T lastItem = items[lastIndex];
            removeLast();
            addFirst(lastItem);
        }
    }
}

Key Points:

  • nextFirst starts to the left of the first element; nextLast starts to the right of the last element.
  • All index arithmetic uses % items.length to wrap around the circular array.
  • Downsizing: array halves when size < items.length / 4 (only when length ≥ 16 to avoid over-shrinking).
  • resize re-maps all elements to indices 0..size-1 in the new array, resetting nextFirst = capacity - 1 and nextLast = size.

Important Keywords & Syntax

  • System.arraycopy(src, srcPos, dest, destPos, length): The standard, highly optimized way to copy data between arrays.
  • Amortized Analysis: Evaluating the average cost of an operation over a long sequence of events (e.g., addLast is O(1) amortized).
  • Garbage Collection: The automatic process of reclaiming memory from objects that are no longer referenced.
  • nulling out: Specifically setting a reference to null to prevent "loitering" and assist the garbage collector.
  • Usage Ratio: The proportion of the underlying array that is actually being used by the list.

Lecture 9 — Inheritance & Interfaces

1. The Problem: The Desire for Generality

Before inheritance, if you wanted to write a method that printed a list, you would have to "overload" it for every single list type:

  • public static void print(AList list)
  • public static void print(SLList list)

This is redundant and hard to maintain. Inheritance allows us to define a Hypernym (a general category) that both classes belong to.

2. Interface Inheritance

An Interface is a "contract" that specifies what a class can do, but not how it does it.

  • Syntax: Use the interface keyword to define the contract and implements to connect a class to that contract.
  • Keywords:
    • interface: Defines the template.
    • implements: Establishes the relationship.
    • @Override: A tag (annotation) that tells the compiler you are purposely redefining a method from the interface. It helps catch typos.

Example Code (Interface):

java 
public interface List61B<Item> {
    public void addFirst(Item x);
    public void addLast(Item x);
    public Item getFirst();
    public int size();
    // ... other method signatures
}

public class SLList<Item> implements List61B<Item> {
    @Override
    public void addLast(Item x) {
        // ... specific SLList logic
    }
}

Example — Deque61B Interface (for LinkedListDeque61B and ArrayDeque61B earlier):

The Deque61B<T> interface from Project 1 demonstrates all of these concepts together: method signatures, a default implementation, and the implements relationship.

java 
import java.util.List;

public interface Deque61B<T> {
    void addFirst(T x);
    void addLast(T x);
    List<T> toList();
    boolean isEmpty();
    int size();
    T removeFirst();
    T removeLast();
    T get(int index);
    T getRecursive(int index);

    /**
     * Default method: removes x items from each end.
     * If size <= 2*x, empties the deque entirely.
     * Demonstrates how default methods provide shared logic
     * without requiring each implementing class to re-write it.
     */
    default void clipEnds(int x) {
        if (x <= 0) { return; }
        if (size() <= 2 * x) {
            while (!isEmpty()) { removeFirst(); }
            return;
        }
        for (int i = 0; i < x; i++) {
            removeFirst();
            removeLast();
        }
    }

    /** Fall 2025 Midterm 1 **/
    default boolean rotateToFront(T x) {
        int rotations = 0;
        while (rotations < size()) {
            if (getFirst().equals(x)) {
                return true;
            }
            addLast(removeFirst());
            rotations += 1;
        }
        return false;
    }

    default boolean rotateToFront(T x) { // Alternate Solution 
        for (int i = 0; i < size(); i++) {
            if (get(i).equals(x)) {
                for (int j = 0; j < i; j++) {
                    addLast(removeFirst());
                }
                return true;
            }
        }
        return false;
    }

    default boolean rotateToFront(T x) { // Alternate Solution 2
        int rotations = 0;
        while (!get(rotations).equals(x) && rotations < size()) {
            addLast(removeFirst());
            rotations++;
        }
        return rotations < size();
    }
}

Key Points:

  • Both LinkedListDeque61B and ArrayDeque61B implement Deque61B<T>, giving them all the method signatures above plus the free clipEnds default.
  • clipEnds may not use new — it can only call the interface's own methods (removeFirst, removeLast, size, isEmpty).
  • The default keyword lets the interface author provide a behavior that all implementors inherit, but any class may @Override it with a more efficient version.

3. Implementation Inheritance (Default Methods)

Interface inheritance tells you what a class does. Implementation inheritance allows you to provide a default behavior that all subclasses can use unless they choose to override it.

  • Keyword: default.
  • Benefit: You only have to write the code once in the interface.

Example Code (Default Method):

java 
public interface List61B<Item> {
    // ... standard signatures ...

    default public void print() {
        for (int i = 0; i < size(); i++) {
            System.out.print(get(i) + " ");
        }
        System.out.println();
    }
}

4. Overloading vs. Overriding

It is crucial to distinguish between these two:

  • Overloading: Multiple methods in the same class with the same name but different signatures (e.g., add(int x) and add(double x)).
  • Overriding: A subclass provides a specific implementation of a method already defined in its parent/interface (using the exact same signature).

5. Summary of Relationships

Inheritance creates a hierarchy between types:

  • Hypernym: The interface (e.g., List61B).
  • Hyponym: The specific implementation (e.g., AList, SLList).

1. Iteration (The Enhanced For Loop)

To use the "enhanced for loop" (e.g., for (T x : set)) on a custom class like ArraySet, your class must follow a specific interface pattern.

  • Iterable Interface: The class must implement Iterable<T>. This requires a method public Iterator<T> iterator().
  • Iterator Interface: This is the object that actually does the work. It must implement hasNext() and next().

Example Code (ArraySet Iteration):

java 
import java.util.Iterator;

A. equals(Object o)

Example Code (Professional equals):

java 
@Override
public boolean equals(Object other) {
    if (this == other) { return true; }                        // Optimization

    if (o.size() != this.size()) { return false; }

Lecture 11 — Subtype Polymorphism & Comparators

1. Subtype Polymorphism

Polymorphism ("many forms") allows a single method to work with different types of objects.

  • The Concept: You can write code that operates on a high-level type (like an interface), and the program will automatically use the specific behavior of the actual object provided at runtime.
  • Example: A max method that works for any list of objects, provided those objects can be compared to one another.

2. Comparing Objects: The Comparable Interface

To give a class a "natural order" (e.g., sorting Dogs by size), the class must implement the Comparable interface.

  • Method: public int compareTo(T other)
  • Return Rules:
    • Negative if this < other.
    • Zero if this == other.
    • Positive if this > other.

Example Code (Natural Order):

java 
public class Dog implements Comparable<Dog> {
    private String name;
    private int size;

    /** Returns negative if this dog is smaller than uddaDog */
    @Override
    public int compareTo(Dog uddaDog) {
        return this.size - uddaDog.size;
    }
}

Example Code (Testing Equality):

java 
public class GoatMeasurement {
    public String name;
    public double size;

    @Override
    public boolean equals(Object o) { // Assume name is never null.
        if (o instanceof GoatMeasurement other)) {
            return (name.equals(other.name) && (Math.abs(size - other.size) <= 0.1));
        }
        return false;
    }
}

3. Flexibility: The Comparator Interface

Sometimes you want to sort objects in a way that is different from their natural order (e.g., sorting Dogs by name instead of size). For this, you use a Comparator.

  • The Strategy: Create a separate nested class that implements Comparator.
  • Method: public int compare(T a, T b)
  • Usage: Pass an instance of this comparator to a sort or max method.

Example Code (Alternative Order):

java 
import java.util.Comparator;

public class Student implements Comparable<Student> {
    public static final Comparator<Student> NAME_COMPARATOR = new NameComparator();
    private String name;
    private int year;

    public Student(String name, int year) {
        this.name = name;
        this.year = year;
    }

    public static class NameComparator implements Comparator<Student> {
        @Override
        public int compare(Student a, Student b) {
            return a.name.compareTo(b.name);
        }
    }

    @Override
    public int compareTo(Student other) {
        return this.year - other.year;
    }
}

Student s1 = new Student("Alice", 2024);
Student s2 = new Student("Bob", 2023);
